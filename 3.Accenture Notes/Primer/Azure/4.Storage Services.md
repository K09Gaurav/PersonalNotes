# Storage Services - PreQuiz

## Question 1

### Question
Which Azure Storage service is a NoSQL data store for semi-structured data?

- A. Table Storage
- B. File Storage
- C. Queue Storage
- D. Blob Storage

---

### Answer
**A. Table Storage**

---

### Explanation

#### Why Correct Answer is Correct

Azure Table Storage is a NoSQL key-value store designed for large amounts of semi-structured data.

Characteristics:

- Schema-less design
- Massive scalability
- Fast access using partition and row keys
- Suitable for structured and semi-structured datasets

Common uses include:

- User profiles
- Metadata
- Device information
- Application logs

---

#### Why Option B is Wrong

Azure File Storage provides shared file systems rather than NoSQL storage.

---

#### Why Option C is Wrong

Queue Storage is used for messaging between applications.

---

#### Why Option D is Wrong

Blob Storage is designed for unstructured data such as images, videos, and documents.

---

## Question 2

### Question

- A. Premium Storage
- B. General Purpose v2 (GPv2)
- C. Blob Storage
- D. General Purpose v1 (GPv1)

---

### Answer

---

General Purpose v2 (GPv2) is the recommended Azure Storage account type.

Benefits:

- Supports all Azure Storage services
- Lower pricing options
- Lifecycle management
- Access tiers (Hot, Cool, Archive)
- Latest Azure storage features

Microsoft recommends GPv2 for most scenarios.

---

#### Why Option A is Wrong

Premium Storage is optimized for high-performance workloads but is not the default choice for most workloads.

---

#### Why Option C is Wrong

Blob Storage accounts focus primarily on blob storage and do not provide the broad functionality of GPv2.

---

#### Why Option D is Wrong

GPv1 is an older account type and lacks many GPv2 capabilities.

### Question
How does the global reach of Azure Storage positively impact user experience, specifically in terms of latency reduction?

- A. Lower costs
- B. Higher durability
- C. Better security
- D. Lower latency

---

### Answer
**D. Lower latency**

---

### Explanation

#### Why Correct Answer is Correct

Azure Storage is available across many regions worldwide. By storing data closer to users, requests travel shorter distances across the network, reducing response times.

Benefits include:

- Faster access to data
- Improved application performance
- Better user experience
- Reduced network delays

This reduction in response time is known as **lower latency**.

---

#### Why Option A is Wrong

Global reach may indirectly affect costs, but the question specifically asks about latency reduction.

---

#### Why Option B is Wrong

Durability refers to protection against data loss, not response speed.

---

#### Why Option C is Wrong

Security is a separate Azure Storage feature and is unrelated to latency.
