## Question 1

### Question
Define Azure Database for PostgreSQL.

- A. A cloud-based virtual machine service
- B. An analytics service for big data processing
- C. A relational database service for PostgreSQL applications in Azure
- D. A distributed file storage service in Azure

---

### Answer
**C. A relational database service for PostgreSQL applications in Azure**

---

### Explanation

#### Why Correct Answer is Correct

Azure Database for PostgreSQL is a fully managed relational database service based on the PostgreSQL database engine.

Features include:

- Managed PostgreSQL environment
- Automatic backups
- High availability
- Security and compliance
- Scalability

It allows organizations to run PostgreSQL workloads without managing underlying infrastructure.

---

#### Why Option A is Wrong

Virtual Machines provide infrastructure, not managed PostgreSQL services.

---

#### Why Option B is Wrong

Big data analytics services include Azure Synapse Analytics and Azure Databricks.

---

#### Why Option D is Wrong

Distributed file storage is handled by Azure Storage services.

---

## Question 3

### Question
How does Azure SQL Database handle automatic failover?

- A. By disabling failover for high availability
- B. By relying on manual intervention
- C. Through automatic detection and redirection of traffic to a standby replica
- D. By triggering a complete system shutdown

---

### Answer
**C. Through automatic detection and redirection of traffic to a standby replica**

---

### Explanation

#### Why Correct Answer is Correct

Azure SQL Database continuously monitors database health.

If a failure occurs:

1. Failure is detected automatically.
2. A standby replica becomes active.
3. Connections are redirected automatically.

This minimizes downtime and supports business continuity.

---

#### Why Option A is Wrong

Failover improves availability; it is not disabled.

---

#### Why Option B is Wrong

Manual intervention is generally not required.

---

#### Why Option D is Wrong

The goal is service continuity, not shutdown.
