# Azure Lab: Create a Web App Using a Docker Container

## Lab Objective

In this activity, you will:

- Create an Azure App Service Web App
- Deploy a website using a Docker container
- Verify the deployed application

---

# Steps to Connect in Azure Portal

1. Click **Start Attempt** and wait for the environment provisioning.
2. Once the environment is created, Azure credentials will be provided.
3. Click **Generate OTP**.
4. Copy the OTP and use it to sign in to the Azure Portal.
5. Complete the activity.
6. Click **Submit Attempt**.

---

# Overview

Azure App Service provides several services for hosting applications:

- Web Apps
- Mobile Apps
- API Apps
- Logic Apps

In this lab, you will create a **Web App** that runs a Docker container containing a welcome page.

---

# Task 1: Create a Web App

## Step 1: Sign In

Open Azure Portal:

```text
https://portal.azure.com
```

---

## Step 2: Open App Services

Navigate to:

```text
All Services
→ App Services
→ + Add
→ + Create
→ + New
```

---

## Step 3: Configure the Basics Tab

> Replace `xxxx` with letters or numbers to make the web app name globally unique.

### Basic Settings

| Setting | Value |
|----------|--------|
| Subscription | Use default supplied |
| Resource Group | Use default supplied |
| Name | myDockerWebAppxxxx |
| Publish | Container |
| Operating System | Linux |
| Region | Your nearest region |
| Pricing Plan | Basic B1 |

### Example

```text
myDockerWebApp1234
myDockerWebApp2025
myDockerWebAppabc1
```

> The Web App name must be globally unique across Azure.

---

## Step 4: Configure the Container Tab

Select:

```text
Container Tab
```

Configure the following settings:

| Setting | Value |
|----------|--------|
| Image Source | Other Container Registries |
| Access Type | Public |
| Registry Server URL | https://index.docker.io |
| Image and Tag | tekstac/webapp |

### Container Configuration Summary

```text
Image Source      : Other Container Registries
Access Type       : Public
Registry URL      : https://index.docker.io
Image             : tekstac/webapp
```

> Startup Command is optional and not required for this lab.

---

## Step 5: Create the Web App

1. Click **Review + Create**.
2. Verify the configuration.
3. Click **Create**.
4. Wait for deployment to complete.

---

# Task 2: Test the Web App

## Step 1: Open the Deployed Resource

After deployment:

```text
Notifications
→ Go to Resource
```

---

## Step 2: Copy the Web App URL

Navigate to:
![Pasted image 20260602164928](../../images/Pasted%20image%2020260602164928.png)

```text
Web App
→ Overview
```

Locate and copy the:

```text
Default Domain / URL
```

Example:

```text
https://mydockerwebapp1234.azurewebsites.net
```

---

## Step 3: Test the Application

1. Open a new browser tab.
2. Paste the copied URL.
3. Press **Enter**.

### Expected Output

```text
Welcome to Azure Container Instances!
```


![Pasted image 20260602164937](../../images/Pasted%20image%2020260602164937.png)

This confirms that:

- The Web App is running successfully.
- The Docker container has been deployed.
- The application is accessible through the public URL.

---

## Step 4: Monitor Application Metrics

Return to:

```text
Web App
→ Overview
```

Scroll down to view monitoring charts such as:

- Requests
- Average Response Time
- Data In
- Data Out

### Observation

If you refresh the website multiple times, Azure App Service telemetry will update and display:

- Increased request count
- Response time statistics
- Network traffic metrics
