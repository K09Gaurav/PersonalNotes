### Question 1

#### Question
Which of the following is a software development practice where members of a team use a version control system and frequently integrate their work to the same location like the main branch?

- A. Continuous Deployment  
- B. Continuous Integration  
- C. Continuous Delivery  
- D. Continuous Monitoring  

---

#### Answer
**B. Continuous Integration**

---

#### Explanation

##### Why B is Correct — Continuous Integration
Continuous Integration (CI) is a development practice where:
- Developers frequently merge code changes
- Changes are integrated into a shared repository or main branch
- Automated builds and tests are triggered after integration

The main goals are:
- Early bug detection
- Faster feedback
- Reduced integration conflicts

CI heavily depends on:
- Version control systems such as Git
- Shared repositories
- Automated testing pipelines

---

##### Why A is Wrong — Continuous Deployment
Continuous Deployment focuses on:
- Automatically deploying validated code to production

It happens after Continuous Integration and Continuous Delivery stages.

---

##### Why C is Wrong — Continuous Delivery
Continuous Delivery ensures:
- Software is always deployment-ready

However, the core activity of frequently integrating code into a shared branch belongs to Continuous Integration.

---

##### Why D is Wrong — Continuous Monitoring
Continuous Monitoring focuses on:
- Observing applications and infrastructure
- Monitoring logs and performance

It does not involve code integration practices.
