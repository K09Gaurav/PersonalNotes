# Pre Quiz

## Question 1

### Question
Identify which statement is true about constructors.

- A. Constructor can be overloaded
- B. Constructor will be invoked explicitly like other methods
- C. Constructor of a class should not have a return type, which means the return type is void
- D. Constructor should have same name as class name, but not case sensitive

---

### Answer
**A. Constructor can be overloaded**

---

### Explanation

#### Why Correct Answer is Correct

Constructor overloading means a class can have multiple constructors with different parameter lists.

Example:

```java
Student()
Student(int id)
Student(int id, String name)
```

All are valid constructors of the same class.

---

#### Why Option B is Wrong

Constructors are invoked automatically during object creation.

```java
new Student();
```

They are not called like normal methods.

---

#### Why Option C is Wrong

Constructors do not have any return type.

Not even `void`.

Incorrect:

```java
public void Student()
```

This becomes a method, not a constructor.

---

#### Why Option D is Wrong

Java is case-sensitive.

Class name and constructor name must match exactly.

---

Compilation fails.
