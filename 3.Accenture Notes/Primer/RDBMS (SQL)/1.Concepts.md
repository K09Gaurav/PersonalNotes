# Pre Quiz

## Question 1

### Question
Database is a shared collection of logically unrelated data, designed to meet the needs of an organization. State True or False.

- A. TRUE
- B. FALSE

---

### Answer
**FALSE**

---

### Explanation

#### Why False is Correct

A database is formally defined as:

> A shared collection of **logically related data** designed to meet the information needs of an organization.

The keyword is **related**.

Data stored in a database is connected in a meaningful way so that it can be organized, retrieved, and managed efficiently.

For example:

- Customer records
- Orders
- Products
- Employees

These entities are logically related to the organization's operations.

Since the statement says **logically unrelated data**, it is incorrect.

Important exam point:

- Logically related → Correct database definition
- Logically unrelated → Incorrect definition

---

#### Why True is Wrong

The statement changes the standard database definition by replacing **related** with **unrelated**, making the statement false.

## Question 2

### Question
Which of the following represents the degree of the relation?

- A. No of Attributes
- B. Cardinality
- C. Domain
- D. No of rows

---

### Answer
**No of Attributes**

---

### Explanation

#### Why Correct Answer is Correct

In the relational model:

- Degree = Number of attributes (columns)
- Cardinality = Number of tuples (rows)

A relation with:

- EmployeeID
- Name
- Salary
- Department

has a degree of 4 because there are four attributes.

Important exam point:

- Degree = Columns
- Cardinality = Rows

---

#### Why Option A is Wrong

This option is actually correct.

Degree is defined as the number of attributes in a relation.

---

#### Why Option B is Wrong

Cardinality refers to the number of rows (tuples) in a relation, not the number of columns.

---

#### Why Option C is Wrong

A domain is the set of valid values that an attribute can contain.

Example:

- Age → Integers from 0 to 120

Domain is unrelated to degree.

---

#### Why Option D is Wrong

The number of rows represents cardinality, not degree.

---

## Question 3

### Question
Which of the following are data models?

- A. Hierarchical
- B. Conceptual
- C. Relational
- D. Network

---

### Answer
**Hierarchical, Conceptual, Relational, Network**

---

### Explanation

#### Why Hierarchical is Correct

The hierarchical model organizes data in a tree-like structure.

Characteristics:

- Parent-child relationships
- One parent can have multiple children
- Common in early database systems

---

#### Why Conceptual is Correct

The conceptual model provides a high-level representation of data requirements.

Characteristics:

- Used during database design
- Focuses on entities and relationships
- Independent of implementation details

---

#### Why Relational is Correct

The relational model organizes data into tables.

Characteristics:

- Rows and columns
- Uses keys and relationships
- Most widely used model today

Examples:

- Oracle
- MySQL
- PostgreSQL
- SQL Server

---

#### Why Network is Correct

The network model organizes data as a graph structure.

Characteristics:

- Supports many-to-many relationships
- More flexible than hierarchical models

---

### Exam Tip

All four options are recognized data models.

When all appear together in a multiple-answer question, the expected answer is usually **all options**.

## Question 4

### Question
Which of the following are DML statements?

- A. TRUNCATE
- B. SELECT
- C. CREATE
- D. INSERT

---

### Answer
**SELECT, INSERT**

---

### Explanation

#### Why SELECT is Correct

SELECT retrieves data from database tables.

Example purpose:

- Viewing records
- Querying information
- Filtering results

Many academic database courses classify SELECT under DML.

---

#### Why INSERT is Correct

INSERT adds new records into a table.

Example purpose:

- Adding employees
- Creating customer records
- Storing transactions

INSERT directly manipulates data.

---

#### Why Option A is Wrong

TRUNCATE is generally classified as a DDL command.

Purpose:

- Removes all rows from a table
- Preserves table structure

---

#### Why Option B is Wrong

This option is actually correct.

SELECT is commonly treated as DML in academic and certification-style examinations.

---

#### Why Option C is Wrong

CREATE is a DDL command.

Purpose:

- Creates tables
- Creates views
- Creates indexes
- Creates database objects

It modifies structure, not data.

---

#### Why Option D is Wrong

This option is actually correct.

INSERT is a standard DML command.

---

### Exam Tip

In some references:

- SELECT is categorized separately as DQL (Data Query Language).

However, many exams include SELECT under DML. For quiz purposes, follow the platform's expected classification.

## Question 5

### Question
Which of the following are considered as constraints?

- A. NOT NULL
- B. CHECK
- C. UNIQUE
- D. NULL

---

### Answer
**NOT NULL, CHECK, UNIQUE**

---

### Explanation

#### Why NOT NULL is Correct

NOT NULL ensures that a column cannot contain a null value.

Purpose:

- Forces users to provide a value
- Maintains data integrity

Example use cases:

- Employee ID
- Customer Name
- Product Code

---

#### Why CHECK is Correct

CHECK enforces a condition on values.

Purpose:

- Restricts invalid data
- Ensures business rules are followed

Examples:

- Age must be greater than 18
- Salary must be positive

---

#### Why UNIQUE is Correct

UNIQUE ensures that duplicate values are not allowed.

Purpose:

- Prevents duplicate entries
- Maintains uniqueness

Examples:

- Email addresses
- Passport numbers
- Employee codes

---

#### Why Option D is Wrong

NULL is not a constraint.

NULL represents:

- Missing value
- Unknown value
- Not applicable value

It does not enforce any rule.

---

### Exam Tip

Common SQL constraints include:

- PRIMARY KEY
- FOREIGN KEY
- UNIQUE
- NOT NULL
- CHECK
- DEFAULT

NULL itself is not a constraint.

## Question 1

### Question
SQL is a case sensitive language and the data stored inside the table are case insensitive. Say True or False?

- A. True
- B. False

---

### Answer
**False**

---

### Explanation

#### Why False is Correct

SQL keywords are generally **not case sensitive**.

Examples:

- SELECT
- select
- Select

are treated the same by most database systems.

The statement claims:

> SQL is a case sensitive language

which is incorrect.

Regarding data stored in tables:

- Case sensitivity of data depends on the database system and collation settings.
- Some databases treat string comparisons as case-sensitive.
- Others treat them as case-insensitive.

Therefore, the entire statement is considered false.

Important exam point:

- SQL commands are generally case-insensitive.
- Object names and stored data may depend on database implementation.

---

#### Why True is Wrong

The statement incorrectly claims SQL itself is case-sensitive.

Most SQL implementations allow keywords in any combination of uppercase and lowercase letters.

---

### Exam Tip

Many certification and academic exams expect:

> SQL is not a case-sensitive language.

Therefore the expected answer is **False**.

## Question 2

### Question

Terms of Relational Model

_______ refers to the range of values that can be stored for an attribute

_______ refers to the columns of the table

_______ refers to the rows of the table

_______ refers to number of rows in the table

_______ refers to number of columns in the table

---

### Answer

**Answer 1:** Domain

**Answer 2:** Attribute

**Answer 3:** Tuple

**Answer 4:** Cardinality

**Answer 5:** Degree

---

### Explanation

#### Why Domain is Correct

A domain specifies the set of permissible values for an attribute.

Examples:

- Age → 0 to 120
- Gender → Male, Female, Other

The domain defines what values are valid.

---

#### Why Attribute is Correct

An attribute represents a column in a relation.

Examples:

- EmployeeID
- EmployeeName
- Salary

Each column is called an attribute.

---

#### Why Tuple is Correct

A tuple represents a row in a relation.

Example:

EmployeeID = 101

EmployeeName = John

Salary = 50000

This complete row is called a tuple.

---

#### Why Cardinality is Correct

Cardinality represents the number of rows in a table.

Example:

If a table contains 100 employee records:

Cardinality = 100

---

#### Why Degree is Correct

Degree represents the number of columns in a table.

Example:

If a table contains:

- EmployeeID
- Name
- Salary
- Department

Degree = 4

---

### Exam Tip

Memorize the following:

- Domain → Allowed values
- Attribute → Column
- Tuple → Row
- Cardinality → Number of rows
- Degree → Number of columns

## Question 3

### Question

Tom has designed a payroll software for XYZ Technology. The software will store salary details into the database and later retrieve the same for future references.

Tom falls under which category of user?

- A. Application Programmer
- B. End User
- C. Network Administrator
- D. DBA

---

### Answer
**Application Programmer**

---

### Explanation

#### Why Application Programmer is Correct

An Application Programmer:

- Develops software applications
- Writes programs that interact with databases
- Designs forms, reports, and business logic

Tom is designing payroll software that stores and retrieves data.

This is exactly the role of an Application Programmer.

---

#### Why Option B is Wrong

An End User uses the software but does not develop it.

Examples:

- Employee entering attendance
- HR staff viewing payroll

Tom is building the software, not merely using it.

---

#### Why Option C is Wrong

A Network Administrator manages:

- Networks
- Routers
- Connectivity
- Communication infrastructure

Database application development is outside this role.

---

#### Why Option D is Wrong

A DBA (Database Administrator):

- Manages databases
- Handles backup and recovery
- Controls security
- Tunes performance

The question focuses on software development rather than database administration.

## Question 5

### Question

Which of the following is not a valid relational database?

- A. Unify
- B. Oracle
- C. MySQL
- D. Sybase

---

### Answer
**Unify**

---

### Explanation

#### Why Unify is Correct

For most academic database quizzes, Unify is considered the non-relational or invalid option among the choices.

The expected exam answer is:

**Unify**

---

#### Why Oracle is Wrong

Oracle is a relational database management system (RDBMS).

Features:

- SQL support
- Transactions
- Multi-user access
- Enterprise database capabilities

---

#### Why MySQL is Wrong

MySQL is a widely used relational database.

Features:

- Open-source
- SQL-based
- Used in web applications

---

#### Why Sybase is Wrong

Sybase is also a relational database management system.

Features:

- SQL support
- Enterprise applications
- Transaction management

---

### Exam Tip

When Oracle, MySQL, and Sybase appear together with Unify, quiz platforms typically expect:

**Unify → Not a valid relational database**

Even if historical database classifications may vary across sources, the expected academic answer is usually **Unify**.
