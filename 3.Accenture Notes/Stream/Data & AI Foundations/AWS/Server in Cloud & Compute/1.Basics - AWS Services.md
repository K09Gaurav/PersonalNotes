# Introduction

**Amazon Web Services (AWS)** is the world's leading cloud computing platform, offering **200+ fully managed cloud services** across computing, storage, databases, networking, security, analytics, machine learning, DevOps, and much more.

Instead of purchasing and maintaining physical infrastructure, organizations can use AWS services on a **pay-as-you-go** basis to build scalable, reliable, and secure cloud applications.

AWS organizes its services into different categories based on their functionality.

> [!IMPORTANT]
> You are **not expected to memorize every AWS service**. Instead, understand the major service categories and know the most commonly used services within each.

---

# What is AWS?

## Definition

**Amazon Web Services (AWS)** is Amazon's cloud computing platform that provides on-demand access to cloud infrastructure and managed services over the Internet.

AWS enables organizations to:

- Build applications
- Store data
- Host websites
- Run databases
- Analyze data
- Deploy machine learning models
- Secure cloud resources
- Automate deployments

without owning physical servers.

# 1. Compute Services

## Definition

Compute services provide the processing power required to run applications.

Instead of purchasing physical servers, AWS allows users to launch virtual servers or execute code on demand.

---

## Amazon EC2 (Elastic Compute Cloud)

### Definition

Amazon **EC2** provides **virtual machines** (called **Instances**) that allow users to run applications in the cloud.

Think of EC2 as renting a virtual computer.

### Features

- Virtual Servers
- Multiple Operating Systems
- Flexible CPU and Memory options
- Auto Scaling support
- Pay-as-you-go pricing

### Common Use Cases

- Hosting websites
- Running enterprise applications
- Development and testing
- Backend APIs

> [!TIP]
> **EC2 = Virtual Machine in AWS**

---

## Amazon Elastic Container Service (ECS)

### Definition

Amazon **ECS** is a fully managed service for running and managing **Docker containers**.

It eliminates much of the operational work involved in container management.

### Use Cases

- Microservices
- Containerized applications
- Scalable web services

---

## AWS Lambda

### Definition

AWS **Lambda** is a **serverless compute service**.

Developers upload code, and AWS automatically executes it when triggered by an event.

No server management is required.

### Benefits

- Serverless
- Automatic scaling
- Pay only for execution time
- Event-driven architecture

### Common Triggers

- File upload
- HTTP request
- Database update
- Scheduled event

> [!TIP]
> **Lambda = Run code without managing servers.**

---

# 2. Storage Services

Storage services provide reliable and scalable cloud storage solutions.

---

## Amazon EBS (Elastic Block Store)

### Definition

Amazon **EBS** provides **block storage** volumes that can be attached to EC2 instances.

It behaves like a virtual hard disk.

### Features

- Persistent storage
- High performance
- Supports snapshots
- Suitable for operating systems and databases

### Common Use Cases

- Operating system disks
- Database storage
- Enterprise applications

---

## Amazon EFS (Elastic File System)

### Definition

Amazon **EFS** provides a fully managed **network file system** that can be shared by multiple EC2 instances simultaneously.

### Features

- Shared storage
- Automatically scales
- Supports Linux workloads

### Common Use Cases

- Shared application data
- Content management systems
- Web server file sharing

---

# EBS vs EFS

| Feature | Amazon EBS | Amazon EFS |
|----------|------------|------------|
| Storage Type | Block Storage | File Storage |
| Shared Across Multiple EC2s | No | Yes |
| Typical Use | Operating System & Databases | Shared Files |
| Performance | Very High | High |

# 3. Analytics Services

Analytics services help organizations process, analyze, and visualize large volumes of data.

---

## Amazon QuickSight

### Definition

Amazon **QuickSight** is AWS's Business Intelligence (BI) and data visualization service.

It creates:

- Dashboards
- Charts
- Reports
- Business analytics

### Example

Sales dashboard displaying monthly revenue trends.

---

## Amazon Athena

### Definition

Amazon **Athena** allows users to query data stored in **Amazon S3** using standard SQL.

No database servers need to be managed.

### Benefits

- Serverless
- SQL-based
- Pay-per-query

### Common Use Cases

- Log analysis
- Data exploration
- Reporting

---

## Amazon Redshift

### Definition

Amazon **Redshift** is AWS's fully managed **Data Warehouse** service.

Designed for:

- Business Intelligence
- Analytics
- Reporting
- Big Data

### Common Use Cases

- Enterprise reporting
- Data warehousing
- Historical data analysis

> [!TIP]
> **Redshift = Data Warehouse**

---

# 4. Application Integration

Application Integration services allow applications to communicate with one another.

---

## Amazon SQS (Simple Queue Service)

### Definition

Amazon **SQS** is a fully managed **Message Queue** service.

It enables asynchronous communication between applications.

### Features

- Reliable messaging
- FIFO support
- Decoupled architecture
- Fault tolerance

### Common Use Cases

- Background processing
- Order processing
- Task queues

> [!TIP]
> **SQS = Queue**

---

## Amazon SNS (Simple Notification Service)

### Definition

Amazon **SNS** is AWS's **Notification Service**.

It sends notifications to:

- Email
- SMS
- Mobile Push
- HTTP endpoints
- AWS services

### Common Use Cases

- Alerts
- Notifications
- System monitoring

> [!TIP]
> **SNS = Notifications**

---

# SQS vs SNS

| Amazon SQS | Amazon SNS |
|-------------|------------|
| Queue | Notification |
| Application-to-Application | Application-to-Person/Application |
| Stores Messages | Broadcasts Messages |

# 5. Cost Management

Cloud resources generate usage-based charges.

AWS provides tools to monitor and control spending.

---

## AWS Budgets

### Definition

AWS **Budgets** allows organizations to define spending limits.

When spending approaches or exceeds the configured budget:

AWS sends notifications.

### Benefits

- Cost monitoring
- Budget alerts
- Expense forecasting

# 6. Database Services

AWS supports both **Relational** and **NoSQL** databases.

---

## Relational Databases

AWS supports popular database engines including:

- MySQL
- Oracle
- Microsoft SQL Server

These are commonly managed using **Amazon RDS (Relational Database Service)**.

### Best For

- Structured data
- Banking
- ERP systems
- Enterprise applications

---

## Amazon DynamoDB

### Definition

Amazon **DynamoDB** is AWS's fully managed **NoSQL Key-Value Database**.

### Features

- Serverless
- High performance
- Automatic scaling
- Millisecond latency

### Common Use Cases

- Gaming
- Mobile apps
- Shopping carts
- User sessions

---

## MongoDB

MongoDB is a popular **Document Database**.

Although MongoDB itself is not an AWS-native service, it can be deployed on AWS or used through **Amazon DocumentDB**, which is compatible with MongoDB APIs.

### Best For

- JSON documents
- Flexible schemas
- Content management
- Catalog applications

---

# Relational vs NoSQL

| Relational Database | NoSQL Database |
|----------------------|----------------|
| Tables | Documents / Key-Value |
| Fixed Schema | Flexible Schema |
| SQL | Non-SQL |
| MySQL, Oracle | DynamoDB, MongoDB |

# 7. Developer Tools

AWS provides services to simplify software development and deployment.

---

## AWS Cloud9

### Definition

AWS Cloud9 was a cloud-based Integrated Development Environment (IDE).

Developers could write, run, and debug code directly from a browser.

> [!NOTE]
> **AWS Cloud9 is no longer available to new customers.**
>
> AWS recommends using:
>
> - AWS IDE Toolkits
> - Amazon SageMaker Studio
> - VS Code Toolkit

---

## AWS CodePipeline

### Definition

AWS **CodePipeline** automates the software release process.

It supports **Continuous Integration (CI)** and **Continuous Delivery (CD)**.

### Pipeline Stages

- Build
- Test
- Deploy

### Benefits

- Automated deployments
- Faster releases
- Reduced manual effort

> [!TIP]
> **CodePipeline = Continuous Integration / Continuous Delivery**

# 8. Security Services

Security is one of AWS's strongest capabilities.

---

## AWS Key Management Service (KMS)

### Definition

AWS **KMS** manages encryption keys.

Used to:

- Encrypt data
- Decrypt data
- Secure storage

> [!TIP]
> **KMS = Encryption**

---

## AWS Shield

### Definition

AWS **Shield** protects applications from **Distributed Denial of Service (DDoS)** attacks.

### Benefits

- Automatic protection
- Network security
- High availability

---

## AWS Identity and Access Management (IAM)

### Definition

AWS **IAM** controls:

- Who can access AWS resources.
- What actions they can perform.

### Features

- Users
- Groups
- Roles
- Policies
- Least Privilege

> [!TIP]
> **IAM = Authentication & Authorization**

# Interview One-Liners

**Amazon EC2**
> AWS service that provides scalable virtual machines in the cloud.

**Amazon ECS**
> A managed container orchestration service for running Docker containers.

**AWS Lambda**
> A serverless compute service that runs code in response to events without managing servers.

**Amazon EBS**
> Persistent block storage for Amazon EC2 instances.

**Amazon EFS**
> A scalable shared file storage service for Linux-based workloads.

**Amazon Athena**
> A serverless query service that analyzes data stored in Amazon S3 using SQL.

**Amazon Redshift**
> AWS's fully managed petabyte-scale data warehouse service.

**Amazon SQS**
> A fully managed message queue service for asynchronous application communication.

**Amazon SNS**
> A publish/subscribe messaging service used to send notifications via email, SMS, and other protocols.

**AWS CodePipeline**
> A continuous integration and continuous delivery (CI/CD) service that automates application release workflows.

**AWS IAM**
> A service that securely manages user identities, roles, and permissions for AWS resources.

**AWS KMS**
> A managed service for creating and managing cryptographic encryption keys.

**AWS Shield**
> A managed DDoS protection service that safeguards AWS applications against network attacks.
