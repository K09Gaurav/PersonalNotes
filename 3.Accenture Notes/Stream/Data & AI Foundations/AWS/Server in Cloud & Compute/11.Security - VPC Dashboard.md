# Lab: Explore the Amazon VPC Dashboard

## Objective

Explore the **Amazon VPC Dashboard** and understand the major components available for managing networking resources in AWS.

> **Note:** This lab is a walkthrough of the VPC Dashboard. No VPCs or networking resources are created in this exercise.

---

# Part A - Open the VPC Dashboard

1. Sign in to the **AWS Management Console**.
2. Search for **VPC** in the search bar.
3. Select the **VPC** service.

# Part B - VPC Dashboard Overview

The VPC Dashboard displays an overview of all Virtual Private Cloud resources available in the selected AWS Region.

From this dashboard, you can:

- View all networking resources
- Monitor resource counts
- Launch the VPC Wizard
- Navigate to networking services

![Pasted image 20260728230019](../../../images/Pasted%20image%2020260728230019.png)

# 1. Resource Summary

The **Resource Summary** section provides a quick overview of networking resources available in your AWS account for the selected Region.

Resources displayed include:

- VPCs
- Subnets
- Route Tables
- Internet Gateways
- Network ACLs
- Endpoints
- Other VPC-related resources

---

# 2. Services Under VPC

The left navigation pane contains all services associated with Amazon VPC.

---

## Your VPCs

Displays all VPCs created in the selected Region.

From this page you can:

- View all VPCs
- Select a VPC
- View VPC details
- Create a new VPC

Each VPC is assigned:

- An IPv4 CIDR Block
- (Optional) IPv6 CIDR Block

All resources inside the VPC receive IP addresses from the assigned CIDR block.

---

## Subnets

Displays all subnets created within your VPCs.

A subnet is a smaller range of IP addresses created from the VPC's CIDR block.

Subnets can be created in different Availability Zones (AZs).


---

## Route Tables

Displays all Route Tables associated with your VPCs.

Route Tables contain routing rules that determine where network traffic is directed.


---

## Internet Gateways

Displays all Internet Gateways.

An Internet Gateway allows resources inside a VPC to communicate with the public Internet.


---

# 3. Service Health

The **Service Health** section displays the current operational status of VPC-related AWS services.

This helps identify whether any networking services are experiencing issues.


---

# VPC Wizard

The **VPC Wizard** helps create a custom VPC using guided configuration.

Using the wizard, you can configure resources such as:

- VPC
- Public Subnets
- Private Subnets
- Route Tables
- Internet Gateway
- Other networking components


---
