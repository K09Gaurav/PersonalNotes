# Introduction

**AWS Lambda** is a **serverless compute service** that lets you run code in the cloud **without provisioning or managing servers**.

Instead of creating and maintaining servers, you simply upload your code as a **Lambda Function**, and AWS automatically executes, scales, and manages the underlying infrastructure.

> [!IMPORTANT]
> **AWS Lambda = Run code without managing servers.**

---

# What is AWS Lambda?

AWS Lambda is an event-driven compute service that executes code in response to events.

The uploaded code is called a **Lambda Function**, and each function is designed to perform a **single, specific task**.

Examples:

- Process uploaded files
- Resize images
- Send notifications
- Process database updates
- Execute backend logic

---

# Why Use AWS Lambda?

Lambda is useful when you want to:

- Run code without managing servers
- Automatically scale applications
- Execute code only when required
- Pay only for actual execution time

Applications built using Lambda are called **Serverless Applications** because AWS manages the servers behind the scenes.

---

# How AWS Lambda Works

```text
Event Occurs
      │
      ▼
AWS Lambda Triggered
      │
      ▼
Execute Lambda Function
      │
      ▼
Return Result
```

---

# Lambda Function

A **Lambda Function** is the code that runs inside AWS Lambda.

Characteristics:

- Performs a single task
- Executes only when triggered
- Runs for a maximum of **15 minutes**
- Automatically scales as needed

---

# Key Features

## Serverless Computing

- No server provisioning
- No infrastructure management
- AWS manages scaling and availability

---

## Event-Driven Execution

Lambda runs only when triggered by an event.

Example events:

- File upload
- Database record insertion
- Other AWS service events

---

## Automatic Scaling

AWS automatically creates additional function instances based on incoming requests.

No manual scaling configuration is required.

---

## Pay Only for Usage

You are charged **only for the compute time your function runs**.

If the function is not running, there are no compute charges.

---

## Maximum Execution Time

Each Lambda invocation can run for a maximum of:

```text
15 Minutes
```

---

# Supported Programming Languages

AWS Lambda supports:

- Java
- PowerShell
- Node.js
- C# / .NET
- Python
- Ruby

For Go and other unsupported languages, you can use the **Amazon Linux 2 Custom Runtime**.

---

# Ways to Create a Lambda Function

You can create Lambda functions by:

### AWS Management Console

Write code directly in the browser.

### Local Development

Develop locally and upload the code to AWS Lambda.

> [!TIP]
> The easiest way to author a Lambda function is through the **AWS Management Console**.

# Memory Trick

> [!TIP]
> Think of **AWS Lambda** as a **light switch**:
>
> - Nothing happens until someone flips the switch (an event).
> - It performs one job.
> - It automatically turns off when finished.
> - You only pay while the light is on.
