# Lab: Create and Test an AWS Lambda Function

## Objective

Create a simple AWS Lambda function using a blueprint, configure a test event, execute the function, and delete it after testing.

---

# Step 1 - Open AWS Lambda

1. Sign in to the **AWS Management Console**.
2. Search for **Lambda**.
3. Open the **Lambda** service.

![Pasted image 20260728231239](../../../images/Pasted%20image%2020260728231239.png)

---

# Step 2 - Launch the Create Function Wizard

1. From the Lambda Dashboard, click **Create function**.

![Pasted image 20260728231244](../../../images/Pasted%20image%2020260728231244.png)

---

# Step 3 - Create a Lambda Function

## Select Function Source

Choose:

```text
Use a blueprint
```

Select the **Node.js Hello World** blueprint.

![Pasted image 20260728231254](../../../images/Pasted%20image%2020260728231254.png)


---

## Configure Function

1. Enter a **Function Name**.
2. Under **Permissions**, select:

```text
Create a new role with basic Lambda permissions
```

3. Click **Create function**.

> **Note:** AWS creates an execution role with permissions to write logs to **Amazon CloudWatch Logs**.

![Pasted image 20260728231318](../../../images/Pasted%20image%2020260728231318.png)

---

# Step 4 - Configure a Test Event

1. Open the **Test** tab (or click the **Test** button under the Code tab).
2. Create a new test event.
3. Enter a **Test Event Name**.
4. Modify the JSON event by adding three string values of your choice.
5. Click **Save** (or **Invoke**).

![Pasted image 20260728231331](../../../images/Pasted%20image%2020260728231331.png)

---

# Step 5 - Test the Function

1. Click **Test**.
2. Review the execution results.

Observe:

- Response
- Function Logs
- Execution Status

The sample function reads the JSON event, prints the values to the logs, and returns the first value.

![Pasted image 20260728231350](../../../images/Pasted%20image%2020260728231350.png)![Pasted image 20260728231400](../../../images/Pasted%20image%2020260728231400.png)![Pasted image 20260728231405](../../../images/Pasted%20image%2020260728231405.png)

---

# Step 6 - Delete the Lambda Function

## Delete the Function

1. Go to **Functions**.
2. Select the function.
3. Click:

```text
Actions
    ↓
Delete Function
```

📷 **Image Placeholder – Delete Function**

---

## Delete the IAM Role (Optional Cleanup)

1. Open the **IAM** service.
2. Navigate to:

```text
Roles
```

3. Select the Lambda execution role.
4. Click **Delete**.

![Pasted image 20260728231422](../../../images/Pasted%20image%2020260728231422.png)

> **Note:** Deleting a Lambda function does **not** delete its associated IAM role.

# AWS CLI

## Create a Lambda Function

```bash
aws lambda create-function \
    --function-name MyFunction \
    --runtime nodejs22.x \
    --zip-file fileb://my-function.zip \
    --handler my-function.handler \
    --role arn:aws:iam::xxxxxxxxxxxx:role/service-role/MyFunction-role-tges6bf4
```
