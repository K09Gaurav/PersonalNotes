# Introduction

**AWS Elastic Beanstalk** is a **Platform as a Service (PaaS)** that simplifies the deployment and management of web applications.

With just a few clicks, Elastic Beanstalk automatically provisions and configures the AWS resources required to run your application.

> [!IMPORTANT]
> **Elastic Beanstalk = Deploy your application without manually setting up the infrastructure.**

---

# What is Elastic Beanstalk?

Elastic Beanstalk is an **orchestration service** that automates the deployment of web applications by provisioning the necessary AWS resources.

Instead of manually creating and configuring services like EC2, Load Balancers, or Auto Scaling Groups, you simply upload your application, and Elastic Beanstalk handles the deployment.

---

# Why Use Elastic Beanstalk?

Elastic Beanstalk helps developers focus on writing application code instead of managing infrastructure.

It automates:

- Infrastructure provisioning
- Application deployment
- Capacity provisioning
- Scaling
- Load balancing

---

# How Elastic Beanstalk Works

```text
Upload Application
        │
        ▼
Elastic Beanstalk
        │
        ▼
Automatically Creates
│
├── EC2 Instance(s)
├── Auto Scaling Group
├── Elastic Load Balancer
├── Security Groups
├── (Optional) Database
└── Other Required Resources
        │
        ▼
Application Running
```

---

# Services Provisioned by Elastic Beanstalk

Elastic Beanstalk can automatically provision and configure:

- Amazon EC2 Instances
- Auto Scaling Groups
- Elastic Load Balancers (ELB)
- Security Groups
- Amazon RDS Database (optional)
- Virtual Private Cloud (VPC)

Although Elastic Beanstalk manages these resources, you still retain full control and can administer them individually if needed.

Elastic Beanstalk supports several common web servers, including:

# Deploying Inside a VPC

Applications deployed using Elastic Beanstalk can run inside an **Amazon VPC**, allowing you to use custom networking configurations such as subnets, route tables, and security groups.

**Orchestration Service**

> Elastic Beanstalk can automatically configure Auto Scaling Groups to adjust application capacity based on demand.
