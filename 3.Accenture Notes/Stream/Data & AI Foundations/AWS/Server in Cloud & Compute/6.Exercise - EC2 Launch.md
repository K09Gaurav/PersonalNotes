# Lab: Launch an Amazon EC2 Instance

## Objective

Learn how to launch an **Amazon EC2 Instance** using the AWS Management Console and AWS CLI.

---

# Prerequisites

- AWS Account
- EC2 Service access
- AWS Console login

---

# Part A - Open the EC2 Dashboard

### Step 1 - Open AWS Console

1. Navigate to **Cloud Resources**.
2. Click **Open Cloud Console**.
3. Search for **EC2**.
4. Open the **EC2 Dashboard**.

![Pasted image 20260708181859](../../../images/Pasted%20image%2020260708181859.png)

> [!NOTE]
> The EC2 Dashboard provides access to:
>
> - EC2 Instances
> - AMIs
> - EBS Volumes
> - Load Balancers
> - Auto Scaling
> - Security Groups

---

# Part B - Launch an EC2 Instance

## Step 1 - Launch Instance

1. Click **Launch Instance**.
2. Enter a meaningful **Instance Name**.

Example:

```text
My-EC2-Instance
```


---

## Step 2 - Choose an Amazon Machine Image (AMI)

### What is an AMI?

An **Amazon Machine Image (AMI)** is a template containing:

- Operating System
- Required software
- Application server
- Configuration

For this lab:

- Select **Amazon Linux 2 AMI**

(Free Tier Eligible)

![Pasted image 20260708181942](../../../images/Pasted%20image%2020260708181942.png)

---

## Step 3 - Choose an Instance Type

Select the hardware configuration.

For this exercise:

- **t2.micro**
- Free Tier Eligible

Configuration:

- 1 vCPU
- 1 GiB RAM
- Default Root Volume
- Supports EBS Storage
![Pasted image 20260708181953](../../../images/Pasted%20image%2020260708181953.png)

---

## Step 4 - Create a Key Pair

### Why?

A Key Pair is required to securely connect to the EC2 instance using SSH.

AWS creates:

- Public Key → Stored on EC2
- Private Key (.pem) → Downloaded locally

### Steps

1. Click **Create New Key Pair**
2. Enter a name

Example:

```text
MyKeyPair
```

3. Click **Create Key Pair**
4. Download the **.pem** file

![Pasted image 20260708182008](../../../images/Pasted%20image%2020260708182008.png)

> [!WARNING]
> Download the **.pem** file immediately.
>
> AWS **does not allow you to download it again** if lost.

---

## Step 5 - Configure Network Settings

Expand **Network Settings** and click **Edit**.

### Enable Public IP

Set:

```text
Auto-assign Public IP → Enable
```

This allows public Internet access to the instance.

---

### Configure Security Group

Allow:

```text
SSH
```

Source:

```text
Anywhere (0.0.0.0/0)
```

AWS automatically creates a Security Group.

Take note of its name.
![Pasted image 20260708182047](../../../images/Pasted%20image%2020260708182047.png)

> [!NOTE]
> Security Groups act as a **virtual firewall** for EC2 instances.

---

## Step 6 - Configure Storage

Keep the default storage configuration.

Default storage is sufficient for this lab.

---

After completing the exercise:

1. Select the EC2 Instance.
2. Click **Instance State**.
3. Select:


Available Options:

- Start

- Hibernate
- Terminate

# AWS CLI Equivalent

## Step 1 - Create Key Pair

```bash
aws ec2 create-key-pair \
--key-name MyKeyPair \
--query 'KeyMaterial' \
--output text > MyKeyPair.pem
```

Set correct permissions:

```bash
chmod 400 MyKeyPair.pem
```

---

## Step 2 - Create Security Group

```bash
aws ec2 create-security-group \
--group-name MySecurityGroup \
--description "My security group description"
```

---

## Step 3 - Allow SSH Access

```bash
aws ec2 authorize-security-group-ingress \
--group-name MySecurityGroup \
--protocol tcp \
--port 22 \
--cidr 0.0.0.0/0
```

---

## Step 4 - Launch EC2 Instance

```bash
aws ec2 run-instances \
--image-id ami-xxxxxxxx \
--count 1 \
--instance-type t2.micro \
--key-name MyKeyPair \
--security-groups MySecurityGroup
```

> [!NOTE]
> Replace:`ami-xxxxxxxx` with the correct AMI ID for your AWS Region.

If required, also specify:

- `--subnet-id`
- `--security-group-ids`

# Key Takeaways

- EC2 instances are launched using an **AMI** and an **Instance Type**.
- A **Key Pair** is required for SSH access.
- **Security Groups** control inbound and outbound traffic.
- **Auto-assign Public IP** enables Internet accessibility.
- **EBS** provides persistent storage for EC2.
- AWS CLI can perform all EC2 launch operations programmatically.
