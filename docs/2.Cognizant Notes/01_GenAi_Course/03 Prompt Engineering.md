

### Basic Principles
1. Write Clear and specific instructions
2. Put questions in delimiters
3. Validate if Questions are met or not and evaluate the output
4. Mention examples to tool and ask it to follow them
5. You can set Context 
6. You can set Response Format (ex: summary, json, python, etc.)
7. You Can set the Response Length
8. Additional Info like tone, Creativity and Style can be set as well while Responding

### Goals
1. Summarizing can be done
2. Inferring : ask ai to know if the movie is good or bad, if user is angry or happy with the product
3. Transforming: Language translation , proofreading and correction
4. Expanding : Change expand the style of Content

### 3 - Types of Roles
1. System Role : Sets the Behavior for the Tool and instructs ai to behave in certain way. ex - Setting Personas'
2. Assistant : The Gen ai Tool that is talking to you.
3. User : Asking Specific Questions
