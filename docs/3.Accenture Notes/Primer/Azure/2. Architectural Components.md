# Pre Quiz

## Question 1

### Question

What purpose do Azure Availability Zones serve?

- A. Zones for software development
- B. Geographic locations for billing purposes
- C. Isolated data centers within a region for high availability
- D. Azure customer support zones

---

### Answer

**C. Isolated data centers within a region for high availability**

---

### Explanation

#### Why Correct Answer is Correct

Azure Availability Zones are physically separate data centers within the same Azure region.

Their purpose is to:

- Improve fault tolerance
- Improve business continuity
- Increase service availability
- Protect against data center failures

Applications can be distributed across multiple Availability Zones so that a failure in one zone does not affect the entire application.

---

#### Why Option A is Wrong

Availability Zones are infrastructure components, not software development environments.

---

#### Why Option B is Wrong

Billing is handled through subscriptions and management systems, not Availability Zones.

---

#### Why Option C is Correct

Availability Zones are isolated data centers within an Azure region that provide high availability.

---

#### Why Option D is Wrong

Customer support operations are unrelated to Availability Zones.

---

### Exam Tip

Availability Zone = Separate Data Center within the Same Region
