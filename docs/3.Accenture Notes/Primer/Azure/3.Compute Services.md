# Compute Services - PreQuiz

## Question 1

### Question
What is Azure Container Instances (ACI)?

- A. A service for managing virtual machines
- B. An Azure database service
- C. A tool for monitoring network traffic in Azure
- D. A platform for deploying and managing containers without managing the underlying infrastructure

---

### Answer
**D. A platform for deploying and managing containers without managing the underlying infrastructure**

---

### Explanation

#### Why Correct Answer is Correct

Azure Container Instances (ACI) is a serverless container service that allows developers to run containers directly in Azure without provisioning or managing virtual machines.

Key features:

- Fast container deployment
- No infrastructure management
- Pay only for resources consumed
- Ideal for simple container workloads

ACI is commonly used for batch jobs, testing, automation tasks, and event-driven workloads.

---

#### Why Option A is Wrong

Managing virtual machines is the responsibility of Azure Virtual Machines, not ACI.

---

#### Why Option B is Wrong

ACI is a compute service, not a database service.

---

#### Why Option C is Wrong

Network monitoring is handled by services such as Azure Monitor and Network Watcher.

---

## Question 10

### Question
Azure Container Instances are best suited for:

- A. Database management
- B. Machine learning workloads
- C. Long-running, stateful applications
- D. Short-lived and burstable applications

---

### Answer
**D. Short-lived and burstable applications**

---

### Explanation

#### Why Correct Answer is Correct

ACI excels for workloads that:

- Start quickly
- Run temporarily
- Scale rapidly
- Require minimal infrastructure management

Examples include:

- Batch processing
- Scheduled jobs
- Event-driven tasks
- Development/testing workloads

---

#### Why Option A is Wrong

Database workloads generally require persistent storage and dedicated services.

---

#### Why Option B is Wrong

Machine learning workloads are often better suited for specialized Azure AI and ML services.

---

#### Why Option C is Wrong

Long-running stateful applications are typically better hosted on AKS, App Service, or Virtual Machines.

---

### Exam Tip

Remember the common Azure compute-service mapping:

- **Azure Virtual Machines (VMs)** → Full infrastructure control (IaaS)
- **Azure App Service** → Web apps and APIs (PaaS)
- **Azure Container Instances (ACI)** → Simple, short-lived containers
- **Azure Kubernetes Service (AKS)** → Container orchestration at scale
- **Azure Virtual Desktop (AVD)** → Cloud-hosted desktops and applications

## Question 1

### Question
Which Azure service allows you to deploy and manage virtual machines using a declarative template?

- A. Azure Resource Manager (ARM)
- B. Azure Virtual Machines
- C. Azure Automation
- D. Azure Virtual Network

---

### Answer
**A. Azure Resource Manager (ARM)**

---

### Explanation

#### Why Correct Answer is Correct

Azure Resource Manager (ARM) is Azure's deployment and management service. It uses declarative templates (ARM Templates or Bicep) that define the desired state of Azure resources.

Benefits include:

- Infrastructure as Code (IaC)
- Repeatable deployments
- Consistent environments
- Centralized resource management

ARM templates describe *what* resources should exist rather than *how* to create them step by step.

---

#### Why Option B is Wrong

Azure Virtual Machines provide compute resources but do not provide declarative deployment templates.

---

#### Why Option C is Wrong

Azure Automation automates operational tasks but is not primarily used for declarative infrastructure deployment.

---

#### Why Option D is Wrong

Azure Virtual Network provides networking capabilities and has nothing to do with template-based deployments.
