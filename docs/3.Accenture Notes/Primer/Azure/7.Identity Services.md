## Question 1

### Question
What is Azure Information Protection used for?

- A. Managing access to Azure resources
- B. Monitoring network traffic
- C. Protecting virtual machines
- D. Classifying and protecting data based on sensitivity

---

### Answer
**D. Classifying and protecting data based on sensitivity**

---

### Explanation

#### Why Correct Answer is Correct

Azure Information Protection (AIP) helps organizations:

- Classify sensitive information
- Label documents and emails
- Protect data using encryption
- Control access to sensitive information

Its primary goal is data protection based on data sensitivity.

---

#### Why Option A is Wrong

Managing access to Azure resources is mainly handled through Azure RBAC and Azure Active Directory.

---

#### Why Option B is Wrong

Network monitoring is performed using services such as Azure Monitor and Network Watcher.

---

#### Why Option C is Wrong

Protecting virtual machines is not the primary purpose of Azure Information Protection.

---

What is the purpose of Azure Active Directory Domain Services (Azure AD DS)?

- A. Cloud-based email service
- B. Domain registration service
- C. Provides domain services such as domain join, LDAP, and Kerberos authentication
- D. Azure-based virtual desktop service

---

### Answer
**C. Provides domain services such as domain join, LDAP, and Kerberos authentication**

---

### Explanation

#### Why Correct Answer is Correct

Azure Active Directory Domain Services (Azure AD DS) provides managed domain services without requiring organizations to deploy and manage domain controllers.

Features include:

- Domain Join
- LDAP support
- Kerberos authentication
- Group Policy support
- NTLM authentication

It enables legacy applications to use traditional Active Directory features in Azure.

---

#### Why Option A is Wrong

Azure AD DS does not provide email services.

---

#### Why Option B is Wrong

Domain registration involves purchasing internet domain names and is unrelated to Azure AD DS.

---

#### Why Option D is Wrong

Virtual desktop services are provided through Azure Virtual Desktop.

### Question
Which Azure service allows you to manage access to external resources for partners and customers?

- A. Azure AD Domain Services
- B. Azure AD Identity Protection
- C. Azure AD External Identities
- D. Azure Active Directory B2C (Azure AD B2C)

---

### Answer
**C. Azure AD External Identities**

---

### Explanation

#### Why Correct Answer is Correct

Azure AD External Identities provides:

- Partner access management
- Customer identity management
- Guest user collaboration
- External user authentication

It is Microsoft's modern solution for managing identities outside the organization.

---

#### Why Option A is Wrong

---

#### Why Option B is Wrong

Identity Protection focuses on risk detection and MFA enforcement.

Current Microsoft documentation positions **Azure AD B2C as part of Azure AD External Identities**. If the question mentions both **partners and customers**, Azure Fundamentals exams typically expect **Azure AD External Identities**.
