# PreQuiz

## Question 1

### Question
What is the purpose of Azure Advisor?

- A. To provide security recommendations
- B. To recommend virtual network configurations
- C. To offer financial advice
- D. To give performance optimization suggestions

---

### Answer
**D. To give performance optimization suggestions**

---

### Explanation

#### Why Correct Answer is Correct

Azure Advisor is a recommendation service that analyzes Azure resources and suggests improvements.

It provides recommendations in areas such as:

- Performance
- Reliability
- Security
- Cost Optimization
- Operational Excellence

In certification exams, Azure Advisor is most commonly associated with optimization recommendations.

---

#### Why Option A is Wrong

Azure Advisor does provide security recommendations, but that is only one category of recommendations and not its primary overall purpose.

---

#### Why Option B is Wrong

Azure Advisor is not specifically designed for virtual network configuration.

---

#### Why Option C is Wrong

Azure Advisor does not provide financial or investment advice.

---

## Question 2

### Question
What does the "Availability SLA" measure in Azure?

- A. Network latency
- B. Data transfer speed
- C. Security compliance
- D. Uptime and reliability

---

### Answer
**D. Uptime and reliability**

---

### Explanation

#### Why Correct Answer is Correct

A Service Level Agreement (SLA) defines Microsoft's commitment regarding service availability.

Availability SLA measures:

- Expected uptime
- Service reliability
- Guaranteed availability percentage

Example:

- 99.9% uptime
- 99.95% uptime
- 99.99% uptime

Higher SLA percentages generally indicate greater availability.

---

#### Why Option A is Wrong

Latency measures response time, not SLA availability.

---

#### Why Option B is Wrong

Data transfer speed is unrelated to availability guarantees.

---

#### Why Option C is Wrong

Security compliance is measured using compliance frameworks and certifications.

---

- B. Compute
- C. Data Transfer
- D. Networking

---

### Answer

---

### Explanation

#### Why Correct Answer is Correct

Compute is usually the largest cost component of an Azure Virtual Machine.

Compute costs are determined by:

- VM size
- Number of vCPUs
- Amount of RAM
- Operating system licensing
- Running duration

Larger VMs consume more compute resources and therefore cost more.

---

#### Why Option C is Wrong

Data transfer can increase costs but is typically not the primary cost driver.

---

#### Why Option D is Wrong

---

### Exam Tip

For Azure Fundamentals exams, when asked for the primary factor affecting VM cost, the expected answer is usually **Compute**.
