# Azure Lab: Create a Virtual Machine and Configure a Website

## Lab Objective

In this activity, you will:

- Create a Virtual Machine with Windows Server 2025 in Azure
- Enable required ports
- Configure a website

---

# Steps to Connect in Azure Portal

1. Click **Start Attempt** and wait for the environment provisioning.
2. Once the environment is created, Azure credentials will be provided.
3. Click **Generate OTP**.
4. Copy the OTP and use it to sign in to the Azure Portal.
5. Complete the activity.
6. Click **Submit Attempt**.

---

# Task 1: Create the Virtual Machine

## Step 1: Sign In

- Open Azure Portal:
  - https://portal.azure.com

---

## Step 2: Create a New Virtual Machine

Navigate to:

```text
All Services
→ Virtual Machines
→ + Add
→ + Create
→ + New
→ Virtual Machine
```

---

## Basics Tab Configuration

| Setting | Value |
|----------|--------|
| Subscription | Use default supplied |
| Resource Group | Use default supplied |
| Virtual Machine Name | myVM |
| Region | Your nearest region |
| Security Type | Standard |
| Image | Windows Server 2025 Datacenter - x64 Gen2 |
| Size | Standard D2S V3 / Standard_DS1_V2 / Standard_B1ms |
| Administrator Username | azureuser |
| Administrator Password | Password@123 |
| Inbound Port Rules | Allow selected ports |
| Select Inbound Ports | RDP (3389) and HTTP (80) |
| OS Disk Type | Standard SSD (Locally Redundant Storage) |

---

## Networking Tab Configuration

Verify that the following inbound ports are selected:

- HTTP (80)
- RDP (3389)

---

## Management Tab Configuration

### Monitoring Settings

| Setting | Value |
|----------|--------|
| Boot Diagnostics | Disable |

---

## Create the Virtual Machine

1. Leave all remaining settings as default.
2. Click **Review + Create**.
3. Wait until **Validation Passed** appears.
4. Click **Create**.
5. Deployment may take **5–7 minutes**.
6. Monitor progress through:
   - Deployment page
   - Notifications (Bell icon)

---

# Task 2: Install Web Server on the VM

## Step 1: Open Run Command

Navigate to:

```text
Virtual Machine (myVM)
→ Operations
→ Run Command
```

![Pasted image 20260602164247](../../images/Pasted%20image%2020260602164247.png)

---

## Step 2: Run PowerShell Script

1. Select:

```text
RunPowerShellScript
```

2. Enter the following command:

```powershell
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
```

3. Click **Run** to execute the command.

### What This Command Does

- Installs Internet Information Services (IIS)
- Installs required web server components
- Installs IIS management tools

---

## Step 3: Get the Public IP Address

Navigate to:

```text
Virtual Machine (myVM)
→ Overview
```

Copy the VM's **Public IP Address**.

---

## Step 4: Verify the Web Server

1. Open a web browser.
2. Paste the VM's Public IP Address into the address bar.
3. Press **Enter**.

### Expected Result

You should see the default IIS welcome page:
![Pasted image 20260602164752](../../images/Pasted%20image%2020260602164752.png)

```text
Internet Information Services (IIS) Welcome Page
```

This confirms that:

- The VM is running successfully.
- IIS has been installed.
- Port 80 (HTTP) is open.
- The web server is publicly accessible.

---

## Step 5: Submit the Lab

1. Return to the lab environment.
2. Click **Evaluate**.
3. Review your results.

---

# Lab Summary

You successfully:

- Created a Windows Server 2025 Virtual Machine.
- Configured inbound networking rules.
- Enabled HTTP (80) and RDP (3389) access.
- Installed IIS Web Server using PowerShell.
- Verified website accessibility using the VM's public IP address.

## Key Command

```powershell
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
```

## Outcome

The VM now hosts a publicly accessible IIS web server. Any web application can be deployed to this virtual machine and made available through its public IP address.
