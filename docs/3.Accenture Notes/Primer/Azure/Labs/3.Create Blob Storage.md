# Azure Lab: Create Blob Storage

## Lab Objective

In this activity, you will:

- Create a Storage Account in Azure
- Create a Blob Container
- Upload files to the container
- Monitor the Storage Account

---

# Steps to Connect in Azure Portal

1. Click **Start Attempt** and wait for the environment provisioning.
2. Once the environment is created, Azure credentials will be provided.
3. Click **Generate OTP**.
4. Copy the OTP and use it to sign in to the Azure Portal.
5. Complete the activity.
6. Click **Submit Attempt**.

---

# Overview

Azure Blob Storage is Microsoft's object storage solution for storing large amounts of unstructured data such as:

- Images
- Videos
- Documents
- Backups
- Log files

In this lab, you will create a Storage Account, create a Blob Container, upload files, and explore monitoring features.

---

# Task 1: Create a Storage Account

## Step 1: Sign In

Open Azure Portal:

```text
https://portal.azure.com
```

---

## Step 2: Open Storage Accounts

Navigate to:

```text
All Services
→ Storage Accounts
→ + Add
→ + Create
→ + New
```

---

## Step 3: Configure the Basics Tab

> Replace `xxxxx` with letters or numbers to make the storage account name globally unique.

### Storage Account Settings

| Setting | Value |
|----------|--------|
| Subscription | Use default supplied |
| Resource Group | Use default supplied |
| Storage Account Name | storageaccountxxxxx |
| Location | Your nearest region |
| Performance | Standard |
| Account Kind | StorageV2 (General Purpose v2) |
| Replication | Locally Redundant Storage (LRS) |

### Example Names

```text
storageaccount12345
storageaccount2025
storageaccountabc12
```

### Naming Rules

- Must be globally unique
- Only lowercase letters and numbers
- No spaces or special characters

---

## Step 4: Validate and Create

1. Click **Review + Create**.
2. Wait for Azure validation.
3. After validation succeeds, click **Create**.
4. Wait until deployment completes.

---

## Step 5: Verify Creation

Navigate to:

```text
Home
→ Storage Accounts
```

Confirm your new storage account appears in the list.

# Task 2: Work with Data Storage

## Step 1: Open Containers

Navigate to:

```text
Storage Account
→ Data Storage
→ Containers
```

---

## Step 2: Create a Blob Container

Click:

```text
+ Container
```

Configure the following settings:

| Setting | Value |
|----------|--------|
| Name | container1 |
| Public Access Level | Private (No Anonymous Access) |

Click:

```text
Create / OK
```

![Pasted image 20260602165219](../../images/Pasted%20image%2020260602165219.png)
---

## Step 3: Download an Image

1. Open a new browser window.
2. Search Bing for an image of a flower.
3. Right-click the image.
4. Save the image to your local machine or VM.

---

## Step 4: Upload the Image

Navigate to:

```text
Storage Account
→ Containers
→ container1
→ Upload
```

Steps:

1. Click **Browse Files**.
2. Select the flower image.
3. Expand **Advanced** settings (optional review).
4. Leave default values.
5. Click **Upload**.

---

## Step 5: Verify Upload

After upload completes:

```text
container1
→ Uploaded File
```

The image should now appear in the container.

### Available File Options

Right-click the uploaded blob and review options:

- View/Edit
- Download
- Properties
- Delete

---

## Notes

You can upload multiple blobs into the same container.

Examples:

```text
flower.jpg
document.pdf
image.png
video.mp4
```

All uploaded files will appear inside the container.

---
