# Pre Quiz


## Question 1

### Question
Predict the output

```java
int a = 0;

if(a)
    System.out.println("Hello");
else
    System.out.println("Hai");
```

- A. Compilation Fails
- B. Need to include braces { } for the code to work
- C. Hai
- D. Hello

---

### Answer
**Compilation Fails**

---

### Explanation

#### Why Correct Answer is Correct
In Java, the condition of an `if` statement must evaluate to a **boolean** value.

Valid examples:

```java
if(true)
if(a > 0)
if(flag)
```

Invalid example:

```java
if(a)
```

because `a` is an integer.

Unlike C/C++, Java does not automatically convert integers to boolean values.

Important exam points:
- Java requires boolean expressions inside `if`.
- Integers cannot be used directly as conditions.

---

#### Why Option A is Correct
Compilation fails because `a` is an int, not a boolean.

---

#### Why Option B is Wrong
Braces are optional for a single statement.

---

#### Why Option C is Wrong
The code never compiles.

---

#### Why Option D is Wrong
The code never compiles.

## Question 2

### Question
What will be the output of the program?

```java
public class Sample
{
    public static void main(String[] args)
    {
        int i = 10;

        do

        while (i < 10)
        {
            System.out.print("The value of i is " + i);
        }

        while (i > 10);
    }
}
```

- A. The value of i is 10
- B. Compilation error
- C. The value of i is 10 The value of i is 10
- D. No output is produced

---

### Answer
**Compilation error**

---

### Explanation

#### Why Correct Answer is Correct
The code contains invalid loop syntax.

The structure:

```java
do
while(i < 10)
{
}
while(i > 10);
```

does not follow Java grammar.

Correct syntax should be:

```java
do
{
}
while(condition);
```

Because the code is syntactically incorrect, compilation fails.

Important exam points:
- `do-while` syntax must contain a statement/block after `do`.
- Incorrect loop structure causes compilation failure.

---

#### Why Option A is Wrong
Program does not compile.

---

#### Why Option B is Correct
The syntax is invalid.

---

#### Why Option C is Wrong
Program never executes.

---

#### Why Option D is Wrong
Compilation fails before execution.

## Question 4

### Question
Which of the following statements about case constants in a Java switch construct is correct?

- A. If a case constant matches the expression, execution starts from that case and continues sequentially until a break is encountered or the switch block ends.
- B. If no case matches and there is no default label, the switch statement will terminate with a compilation error.
- C. If two case labels have the same constant value, the code will compile and the last occurrence will be used.
- D. If no case matches and there is no default label, then it will result in a compilation error.
- E. If no case matches and there is no default label, the program will terminate abnormally.

---

### Answer
**If a case constant matches the expression, execution starts from that case and continues sequentially until a break is encountered or the switch block ends.**

---

### Explanation

#### Why Correct Answer is Correct
Java switch statements allow **fall-through** behavior.

Example:

```java
case 1:
    statement1;
case 2:
    statement2;
```

If case 1 matches and there is no break:

```java
statement1
statement2
```

both execute.

Important exam points:
- Matching case starts execution.
- Execution continues until break or switch ends.

---

#### Why Option A is Correct
This accurately describes switch fall-through.

---

#### Why Option B is Wrong
No compilation error occurs.

---

#### Why Option C is Wrong
Duplicate case values cause compilation failure.

---

#### Why Option D is Wrong
No compilation error occurs.

---

#### Why Option E is Wrong
Program simply skips the switch block.
