## Question 1

### Question
What will be the output of the following code?

```java
int i = 20;

if(i > 10)
{
    System.out.println("The value of i is " + i);
    i++;

    if(i % 2 != 0)
        break;
}
```

- A. Code compiles but will not execute
- B. The value of i is 10
- C. The value of i is 20
- D. Compilation fails

---

### Answer
**Compilation fails**

---

### Explanation

#### Why Correct Answer is Correct
The `break` statement can only be used inside:

- loops (`for`, `while`, `do-while`)
- switch statements

In this code, `break` appears inside an `if` block that is not inside any loop or switch.

Therefore:

```java
Compilation Error
```

Important exam points:
- `break` cannot be used independently inside an `if`.
- It must belong to a loop or switch construct.

---

#### Why Option A is Wrong
Compilation itself fails.

---

#### Why Option B is Wrong
Program never compiles.

---

#### Why Option C is Wrong
Program never compiles.

---

#### Why Option D is Correct
Illegal use of `break` causes a compilation error.

```java

b = 0
```

| b | Action |
|---|---|
