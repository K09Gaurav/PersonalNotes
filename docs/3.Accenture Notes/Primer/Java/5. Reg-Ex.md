## Question 2

### Question

Assume that the ID of an employee should start with:

- CBE
- BLR
- HYD

followed by:

- hyphen (-)

followed by:

- exactly 4 digits

Choose the apt regular expression.

Options:

- A. `(CBE/HYD/BLR)[-][0-9]{4}`
- B. `(CBE\|HYD\|BLR)[-][0-9]{4}`
- C. `[CBE/HYD/BLR][-][0-9]*`
- D. `[CBE\|HYD\|BLR][-][0-9]*`
- E. `[CBE\|HYD\|BLR][-][0-9]{4}`

---

### Answer

**(CBE|HYD|BLR)[-][0-9]{4}**

---

### Explanation

#### Why Correct Answer is Correct

`|` is the regex OR operator.

```regex
(CBE|HYD|BLR)
```

matches:

```text
CBE
HYD
BLR
```

Then:

```regex
[-]
```

matches a hyphen.

Then:

```regex
[0-9]{4}
```

matches exactly four digits.

Valid examples:

```text
CBE-1234
HYD-9999
BLR-0001
```

---

### Why Other Options Are Wrong

#### Option A

```regex
(CBE/HYD/BLR)
```

Uses `/` instead of regex OR `|`.

---

#### Option C

```regex
[CBE/HYD/BLR]
```

Square brackets define a character class.

This matches only one character, not the strings CBE, HYD, or BLR.

---

#### Option D

Same issue as Option C.

Additionally allows unlimited digits because of `*`.

---

#### Option E

Character class problem remains.

---

### Exam Tip

Use:

```regex
(A|B|C)
```

for alternatives.

Use:

```regex
[A|B|C]
```

only for matching individual characters.

## Question 1

### Question

`\B` means "A word boundary".

- A. True
- B. False

---

### Answer

**False**

---

### Explanation

#### Why Correct Answer is Correct

In Java Regular Expressions:

- `\b` = Word Boundary
- `\B` = Not a Word Boundary

A word boundary exists between a word character (`a-z`, `A-Z`, `0-9`, `_`) and a non-word character.

Examples:

- `\bcat\b` matches the standalone word "cat".
- `\Bcat\B` matches "cat" only when it is not at a word boundary.

---

#### Why True is Wrong

`\B` does not represent a word boundary. It represents the opposite: a position that is not a word boundary.
