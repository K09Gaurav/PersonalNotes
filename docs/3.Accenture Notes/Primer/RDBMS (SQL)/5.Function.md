# Pre Quiz

## Question 1

### Question

To generate a report that shows an increase in the credit limit by 15% for all customers. Customers whose credit limit has not been entered should have the message "Not Available" displayed.

Which SQL statement would produce the required result?

- A. SELECT IFNULL(cust_credit_limit * 0.15,'Not Available') "NEW CREDIT" FROM customers;
- B. All the options
- C. SELECT TO_CHAR(NVL(cust_credit_limit*.15,'Not Available')) "NEW CREDIT" FROM customers;
- D. SELECT NULLIF(cust_credit_limit*.15,'Not Available')"NEW CREDIT" FROM customers;

---

### Answer

**A. SELECT IFNULL(cust_credit_limit * 0.15,'Not Available') "NEW CREDIT" FROM customers;**

---

### Explanation

#### Why Correct Answer is Correct

Since the course is using **MySQL**, the proper function for replacing NULL values is:

```sql
IFNULL(expression, replacement)
```

If `cust_credit_limit` is NULL, the output becomes:

```text
Not Available
```

Otherwise, the 15% increase value is displayed.

---

#### Why Option A is Wrong

This option is actually correct for MySQL.

---

#### Why Option B is Wrong

Not all options are valid.

---

#### Why Option C is Wrong

`NVL()` is an Oracle function, not a MySQL function.

Also mixing numeric and string values inside NVL is problematic.

---

#### Why Option D is Wrong

`NULLIF()` does the opposite operation.

It returns NULL if two expressions are equal.

It is not used to replace NULL values.

---

### Exam Tip

For MySQL:

- IFNULL(value,replacement)

For Oracle:

- NVL(value,replacement)

## Question 2

### Question

ABC company wants to give each employee a $100 salary increment. You need to evaluate the results from the EMP table prior to the actual modification.

If you do not want to store the results in the database, which statement is valid?

- A. You need to add a column to the EMP table.
- B. You need to give the arithmetic expression that involves the salary increment in the DISPLAY clause of the SELECT statement.
- C. You need to give the arithmetic expression that involves the salary increment in the SET clause of the UPDATE statement.
- D. You need to give the arithmetic expression that involves the salary increment in the UPDATE clause of the SELECT statement.

---

### Answer

**B. You need to give the arithmetic expression that involves the salary increment in the DISPLAY clause of the SELECT statement.**

---

### Explanation

#### Why Correct Answer is Correct

If the goal is only to view the effect of the salary increase:

- Use SELECT
- Do not use UPDATE

The arithmetic expression can be displayed directly in the SELECT list.

This calculates the increased salary without modifying the database.

---

#### Why Option A is Wrong

No additional column is required.

---

#### Why Option B is Wrong

This option is actually correct.

---

#### Why Option C is Wrong

UPDATE permanently modifies the table.

The question explicitly says not to store the result.

---

#### Why Option D is Wrong

There is no UPDATE clause inside SELECT.

---

### Exam Tip

To preview calculations:

- Use SELECT

To permanently change values:

- Use UPDATE

## Question 4

### Question

Which statement is true regarding the default behavior of the ORDER BY clause?

- A. In a character sort, the values are case-sensitive.
- B. Numeric values are displayed from the maximum to the minimum value if they have decimal positions.
- C. Only those columns that are specified in the SELECT list can be used in the ORDER BY clause.
- D. NULL values are not considered at all by the sort operation.

---

### Answer

**A. In a character sort, the values are case-sensitive.**

---

### Explanation

#### Why Correct Answer is Correct

In many SQL certification-style questions, character sorting is treated as case-sensitive because uppercase and lowercase characters have different ASCII values.

Example:

```text
A
B
a
b
```

may sort differently depending on collation.

This is the expected exam answer.

---

#### Why Option A is Wrong

This option is actually correct according to exam expectations.

---

#### Why Option B is Wrong

ORDER BY defaults to ascending order regardless of decimal values.

---

#### Why Option C is Wrong

Many databases allow ORDER BY columns that are not present in the SELECT list.

---

#### Why Option D is Wrong

NULL values participate in sorting.

They are not ignored.

---

### Exam Tip

Default ORDER BY:

```sql
ORDER BY column
```

means:

```sql
ORDER BY column ASC
```

## Question 5

### Question

To display the names of employees that are not assigned to a department.

Evaluate this SQL statement:

```sql
SELECT last_name, first_name
FROM employee
WHERE dept_id = NULL;
```

Which change should you make to achieve the desired result?

- A. Change the column in the WHERE condition.
- B. Change the operator in the WHERE condition.
- C. Add a second condition to the WHERE condition.
- D. Create an outer join.

---

### Answer

**B. Change the operator in the WHERE condition.**

---

### Explanation

#### Why Correct Answer is Correct

NULL cannot be compared using:

```sql
=
```

or

```sql
<>
```

Correct syntax:

```sql
WHERE dept_id IS NULL
```

The operator must be changed from:

```sql
=
```

to:

```sql
IS NULL
```

---

#### Why Option A is Wrong

The column `dept_id` is correct.

---

#### Why Option B is Wrong

This option is actually correct.

---

#### Why Option C is Wrong

No additional condition is needed.

---

#### Why Option D is Wrong

An outer join is unnecessary.

The requirement is simply to find NULL department values.

---

### Exam Tip

Always remember:

Incorrect:

```sql
column = NULL
```

Correct:

```sql
column IS NULL
```

and

```sql
column IS NOT NULL
```

## Question 1

### Question

Group functions can be used in the WHERE clause. State True or False.

- A. TRUE
- B. FALSE

---

### Answer

**FALSE**

---

### Explanation

#### Why Correct Answer is Correct

Group (aggregate) functions operate on groups of rows.

Examples:

- SUM()
- AVG()
- COUNT()
- MIN()
- MAX()

The WHERE clause filters rows **before** grouping occurs.

Since aggregate values do not exist yet during WHERE evaluation, group functions cannot be used there.

To filter aggregated results, use:

```sql
HAVING
```

instead.

---

#### Why TRUE is Wrong

Aggregate functions are not allowed directly in WHERE because grouping has not yet occurred.

---

### Exam Tip

Remember the execution order:

1. FROM
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. ORDER BY

Aggregate functions are typically used in:

- SELECT
- HAVING

## Question 2

### Question

What will be the output for the below query?

```sql
SELECT CEIL(5.3);
```

- A. 5
- B. None of the options
- C. 5.0
- D. 6

---

### Answer

**D. 6**

---

### Explanation

#### Why Correct Answer is Correct

CEIL() (or CEILING()) returns the smallest integer greater than or equal to the given value.

For:

```text
5.3
```

the next integer is:

```text
6
```

Therefore:

```sql
CEIL(5.3)
```

returns:

```text
6
```

---

#### Why Option A is Wrong

5 would be returned by FLOOR(), not CEIL().

---

#### Why Option B is Wrong

A valid output exists.

---

#### Why Option C is Wrong

CEIL returns an integer value, not 5.0.

---

#### Why Option D is Wrong

This option is actually correct.

---

### Exam Tip

Common numeric functions:

- CEIL(5.3) → 6
- FLOOR(5.3) → 5
- ROUND(5.3) → 5
- ROUND(5.8) → 6

## Question 3

### Question

Single row functions can be nested to any level. State True or False.

- A. TRUE
- B. FALSE

---

### Answer

**TRUE**

---

### Explanation

#### Why Correct Answer is Correct

Single-row functions operate on one row at a time.

Examples:

- UPPER()
- LOWER()
- SUBSTR()
- LENGTH()
- ROUND()

The output of one function can be passed as input to another function.

Therefore they can be nested.

Example concept:

```text
UPPER(TRIM(name))
```

One function's result becomes the input for another.

---

#### Why FALSE is Wrong

SQL allows nesting of single-row functions.

---

### Exam Tip

Single-row functions:

- Return one result per row.
- Can be nested.
- Can be used inside SELECT, WHERE, ORDER BY, etc.

## Question 5

### Question

All columns in the SELECT list that are not in group functions must be in the GROUP BY clause.

State True or False.

- A. TRUE
- B. FALSE

---

### Answer

**TRUE**

---

### Explanation

#### Why Correct Answer is Correct

When aggregate functions are used:

Examples:

- SUM()
- COUNT()
- AVG()

any column appearing in the SELECT list that is not aggregated must appear in GROUP BY.

Example concept:

```sql
SELECT dept_id,
AVG(salary)
FROM employee
GROUP BY dept_id;
```

dept_id is not aggregated, so it must be included in GROUP BY.

This is a fundamental SQL grouping rule.

---

#### Why FALSE is Wrong

Without including non-aggregated columns in GROUP BY, most SQL databases generate an error.

---

### Exam Tip

Rule:

If a column appears in SELECT and is not inside:

- SUM()
- AVG()
- COUNT()
- MIN()
- MAX()

then it must appear in:

```sql
GROUP BY
```

when aggregation is used.
