# Lab: Connect to an Amazon EC2 Instance

## Objective

Learn different methods to connect to a running Linux/Ubuntu EC2 instance.

Connection methods covered:

- EC2 Instance Connect (Browser)
- SSH (Linux/macOS)
- PuTTY (Windows)
- AWS CLI

---

# Prerequisites

- Running EC2 Instance
- Key Pair (.pem)
- Security Group allowing SSH (Port 22)
- Public IPv4 Address or Public DNS

---

# Part A - Start the EC2 Instance

1. Open the **EC2 Dashboard**.
2. Navigate to **Instances**.
3. Select your EC2 instance.
4. Click:

```text
Instance State
    ↓
Start Instance
```

5. Wait until the **Instance State** changes to:

```text
Running
```

![Pasted image 20260708182554](../../../images/Pasted%20image%2020260708182554.png)

---

# Part B - Connect Using EC2 Instance Connect (Recommended)

1. Select the running EC2 instance.
2. Click **Connect**.
3. Open the **EC2 Instance Connect** tab.
4. Verify the connection details.
5. Click **Connect**.

![Pasted image 20260708182608](../../../images/Pasted%20image%2020260708182608.png)

If successful, a browser-based terminal will open.

![Pasted image 20260708182617](../../../images/Pasted%20image%2020260708182617.png)

> [!TIP]
> EC2 Instance Connect is the easiest method because it requires no local SSH client.

# Part C - Connect Using SSH (Linux/macOS)

![Pasted image 20260708182720](../../../images/Pasted%20image%2020260708182720.png)

## Step 1 - Open Terminal

Navigate to the folder containing your downloaded **.pem** file.

---

## Step 2 - Change File Permissions

Restrict access to the private key.

```bash
chmod 400 <path-to-key>.pem
```

Example:

```bash
chmod 400 MyKeyPair.pem
```

> [!IMPORTANT]
> SSH will refuse to use the key if its permissions are too open.

---

## Step 3 - Get Public DNS

In the EC2 Dashboard:

```text
Instances
    ↓
Select Instance
    ↓
Copy Public DNS
```

---

## Step 4 - Connect Using SSH

### Amazon Linux

```bash
ssh -i MyKeyPair.pem ec2-user@<Public-DNS>
```

### Ubuntu

```bash
ssh -i MyKeyPair.pem ubuntu@<Public-DNS>
```

Example:

```bash
ssh -i MyKeyPair.pem ec2-user@ec2-54-xxx-xxx.compute.amazonaws.com
```

---

## Successful Login

If the connection succeeds, you'll see a terminal prompt similar to:

```text
[ec2-user@ip-172-31-xx-xx ~]$
```

![Pasted image 20260708182807](../../../images/Pasted%20image%2020260708182807.png)

---

# Default SSH Usernames

| Operating System | Default Username |
|------------------|------------------|
| Amazon Linux | `ec2-user` |
| Ubuntu | `ubuntu` |
| CentOS | `centos` |
| Debian | `admin` or `debian` |

> [!NOTE]
> Always use the correct default username based on the AMI.

# Part D - Connect Using AWS CLI

Send your SSH public key to the EC2 instance.

```bash
aws ec2-instance-connect send-ssh-public-key \
--instance-id <instance-id> \
--availability-zone <availability-zone> \
--instance-os-user <username> \
--ssh-public-key file://<public-key>.pub
```

Replace:

- `<instance-id>`
- `<availability-zone>`
- `<username>`
- `<public-key>.pub`

with your own values.

# Part E - Connect Using PuTTY (Windows)

## Step 1 - Install PuTTY

Download and install:

- **PuTTY**
- **PuTTYgen**

---

## Step 2 - Convert PEM to PPK

AWS provides a **.pem** key.

PuTTY requires a **.ppk** key.

### Steps

1. Open **PuTTYgen**.
2. Click **Load**.
3. Select the **.pem** file.
4. Click **Save Private Key**.
5. Save as **.ppk**.

![Pasted image 20260708182841](../../../images/Pasted%20image%2020260708182841.png)![Pasted image 20260708182849](../../../images/Pasted%20image%2020260708182849.png)

---

## Step 3 - Open PuTTY

Launch **PuTTY**.

---

- or Public IPv4 Address

# Troubleshooting

## Permission Denied (Public Key)

Possible causes:

- Wrong username
- Wrong key pair
- Incorrect file permissions

Verify:

```bash
chmod 400 MyKeyPair.pem
```

---

## Connection Timed Out

Check:

- EC2 Instance is Running
- Public IP assigned
- Security Group allows SSH (Port 22)

---

## Host Not Found

Verify:

- Correct Public DNS
- Internet connectivity

---

## PuTTY Login Fails

Check:

- Converted `.pem` to `.ppk`
- Correct username
- Correct host address

# Key Takeaways

- EC2 instances must be in the **Running** state before connecting.
- **EC2 Instance Connect** is the quickest browser-based connection method.
- Linux/macOS users connect using **SSH** and a `.pem` key.
- Windows users typically use **PuTTY** with a converted `.ppk` key.
- The correct default username depends on the operating system (e.g., `ec2-user` for Amazon Linux, `ubuntu` for Ubuntu).
- Ensure the Security Group allows **SSH (Port 22)** and the private key has proper permissions.
