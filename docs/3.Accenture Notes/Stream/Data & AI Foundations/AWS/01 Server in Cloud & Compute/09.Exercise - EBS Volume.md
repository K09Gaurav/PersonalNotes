## Objective

Create an empty **Amazon Elastic Block Store (EBS)** volume and learn how to manage it using the AWS Management Console and AWS CLI.

---

# Methods to Create an EBS Volume

AWS provides three ways to create an EBS volume:

### Option 1 - During EC2 Launch
Create and attach an EBS volume while launching a new EC2 instance.

### Option 2 - Create an Empty Volume (This Lab)
Create an empty EBS volume and attach it to an existing EC2 instance later.

### Option 3 - Create from a Snapshot
Create a new EBS volume from an existing snapshot.

---

# Part A - Create an EBS Volume

## Step 1 - Open the EBS Dashboard

1. Open the **AWS Management Console**.
2. Navigate to **EC2 Dashboard**.
3. In the left navigation pane, under **Elastic Block Store**, select **Volumes**.
4. Click **Create Volume**.

---

## Step 2 - Configure Volume

Fill in the required volume specifications.

### Volume Type

Select:

```text
General Purpose SSD (gp2)
```

### Size

Specify the desired storage size.

Example:

```text
10 GB
```

> **Note:** Minimum size is **1 GB** and maximum size is **16,384 GB**.

### Availability Zone

Select the Availability Zone where the volume will be created.

> **Important:** The EBS volume must be in the **same Availability Zone** as the EC2 instance it will be attached to.

### Snapshot ID (Optional)

Leave blank to create an empty volume.

Select a Snapshot ID only if creating the volume from an existing snapshot.

### Tags (Optional)

Add a key-value pair for easier identification.

Example:

| Key | Value |
|-----|-------|
| Name | Udacity_Demo_Volume |

## Step 3 - Create the Volume

1. Review the configuration.
2. Click **Create Volume**.

Wait until the volume state changes to:

```text
Available
```

# EBS Volume Types

| Volume Type | Minimum Size | Maximum Size | Performance |
|-------------|-------------:|-------------:|-------------|
| General Purpose SSD (gp2) | 1 GB | 16,384 GB | 100–3,000 IOPS |
| General Purpose SSD (gp3) | 1 GB | 16,384 GB | 3,000–16,000 IOPS |
| Provisioned IOPS SSD (io1/io2) | 4 GB | 16,384 GB | 100–64,000 IOPS |
| Throughput Optimized HDD (st1) | 500 GB | 16,384 GB | Throughput Optimized |
| Cold HDD (sc1) | 500 GB | 16,384 GB | Cold Storage |
| Magnetic (standard) | 1 GB | 1,024 GB | ~100 IOPS |

# Part B - Delete the EBS Volume

After completing the lab:

1. Open **EC2 Dashboard**.
2. Navigate to **Elastic Block Store → Volumes**.
3. Select the EBS volume.
4. Click:

```text
Actions
    ↓
Delete Volume
```

5. Confirm by clicking **Delete**.


> **Note:** Ensure the volume is **not attached** to an EC2 instance before deleting it.

# AWS CLI

## Create an EBS Volume

```bash
aws ec2 create-volume \
--availability-zone us-east-1a \
--size 10 \
--tag-specifications 'ResourceType=volume,Tags=[{Key=Environment,Value=Production},{Key=Owner,Value=JohnDoe}]'
```
