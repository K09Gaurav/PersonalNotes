# Lab: Create and Manage an Amazon S3 Bucket

## Objective

Learn how to create an Amazon S3 bucket, upload objects, explore bucket properties, and delete the bucket after use.

---

# Step 1 - Create an S3 Bucket

1. Open the **AWS Management Console**.
2. Navigate to **Amazon S3**.
3. Click **Create bucket**.

![[../../../../../../../Pasted image 20260801212353.png]]

---

## Configure the Bucket

### General Configuration

Provide the following:

- **Bucket Name**
  - Must be globally unique.
  - Can only contain lowercase letters, numbers, and hyphens.
  - No spaces or uppercase letters.

- **AWS Region**
  - Select the Region where the bucket will be created.

![[../../../../../../../Pasted image 20260801212410.png]]

---

### Public Access Settings

For this lab:

1. Uncheck:

```text
Block all public access
```

2. Acknowledge the warning.

![[../../../../../../../Pasted image 20260801212418.png]]

> [!WARNING]
> Making a bucket public allows anyone on the internet to access its contents (subject to permissions). This is useful for learning but should be used cautiously in production.

---

### Bucket Versioning

Leave:

```text
Disabled
```

Versioning stores multiple versions of the same object, allowing recovery of deleted or overwritten files.

---

### Default Encryption

Leave the default setting.

If enabled, Amazon S3 automatically encrypts objects stored in the bucket.

---

### Object Lock

Leave:

```text
Disabled
```

Object Lock prevents objects from being modified or deleted for a specified retention period.

---

Click **Create Bucket**.

![[../../../../../../../Pasted image 20260801212447.png]]

---

# AWS CLI - Create Bucket

```bash
aws s3api create-bucket \
--bucket my-unique-bucket-name \
--region us-west-2 \
--create-bucket-configuration LocationConstraint=us-west-2
```

> [!NOTE]
> For the **us-east-1** region, the `--create-bucket-configuration` parameter is not required.

# Step 2 - Upload Files to the Bucket

1. Open the bucket you created.
2. Click **Upload**.
3. Select one or more files or folders.
4. Click **Upload**.


Example:

```bash

```

# Explore Bucket Settings

## 1. Properties

The **Properties** tab allows you to configure additional bucket features.

Common options include:

- Bucket Versioning
- Static Website Hosting
- Default Encryption
- Server Access Logging
- Requester Pays
 

---

### Static Website Hosting

Allows an S3 bucket to host static websites containing files such as:

- HTML
- CSS
- JavaScript
- Images

> [!TIP]
> S3 is a popular and cost-effective solution for hosting static websites.

---

## 2. Permissions

The **Permissions** tab controls who can access the bucket and its objects.

You can configure:

- Bucket Policies
- Access Control Lists (ACLs)
- Public Access Settings
- Cross-Origin Resource Sharing (CORS)

Bucket policies are written in **JSON**.
 

---

## 3. Metrics

The **Metrics** tab displays bucket usage information such as:

- Total Bucket Size
- Number of Objects
- Storage Class Analysis
- Request Metrics
- Data Transfer Statistics
 
---

## 4. Management

The **Management** tab allows you to configure Lifecycle Rules.

Lifecycle Rules can automatically:

- Transition objects to cheaper storage classes
- Archive objects
- Delete old objects
- Expire incomplete multipart uploads
 
---

## 5. Access Points

Access Points provide simplified and scalable ways to grant access to shared datasets stored in S3.

They create dedicated endpoints for accessing bucket data.
 

---

# Step 3 - Delete the Bucket

1. Open **Amazon S3**.
2. Select the bucket.
3. Click **Delete**.
 

---

## If the Bucket Contains Files

Amazon S3 does **not** allow deletion of non-empty buckets.

Before deleting:

1. Open the bucket.
2. Delete all objects.
3. Return to the Buckets page.
4. Delete the bucket.

You must confirm the bucket name before deletion.

# AWS CLI (Useful Commands)

## Upload File

```bash
aws s3 cp file.txt s3://bucket-name/
```

## List Bucket Contents

```bash
aws s3 ls s3://bucket-name
```

## Delete Object

```bash
aws s3 rm s3://bucket-name/file.txt
```

## Delete Bucket

```bash
aws s3 rb s3://bucket-name
```
