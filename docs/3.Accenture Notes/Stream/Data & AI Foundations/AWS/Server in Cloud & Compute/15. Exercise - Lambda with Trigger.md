# Lab: Trigger an AWS Lambda Function Using Amazon S3

## Objective

Create an S3 bucket, configure a Lambda function, trigger it when files are uploaded to the bucket, and verify the invocation.

---

# Prerequisite - Create an S3 Bucket

1. Open the **AWS Management Console**.
2. Navigate to **Amazon S3**.
3. Click **Create bucket**.
4. Enter:
   - **Bucket Name** (must be globally unique)
   - **AWS Region**
5. Uncheck **Block all public access** (for this lab).
6. Leave other settings as default.
7. Click **Create bucket**.

# Step 1 - Create a Lambda Function

1. Open the **AWS Lambda** service.
2. Click **Create function**.
3. Select:

```text
Author from scratch
```

4. Configure the function:

| Setting | Value |
|---------|-------|
| Function Name | Your choice |
| Runtime | Node.js 18.x (or latest) |
| Permissions | Default |

5. Click **Create function**.

![Pasted image 20260728231254](../../../images/Pasted%20image%2020260728231254.png)

---

# Step 2 - Add an S3 Trigger

1. Open the newly created Lambda function.
2. Under **Function Overview**, click **Add Trigger**.
3. Configure:

| Setting | Value |
|---------|-------|
| Trigger | Amazon S3 |
| Bucket | Select your S3 bucket |
| Event Type | All object create events |

4. Acknowledge the recursive invocation warning.
5. Click **Add**.

![Pasted image 20260728231631](../../../images/Pasted%20image%2020260728231631.png)

---

# Step 3 - Configure a Test Event

1. Click **Test**.
2. Create a new test event.

Configure:

| Setting | Value |
|---------|-------|
| Event Template | Hello World |
| Event Name | TestEvent |

Replace the JSON with:

```json
{
  "key1": "Your Name"
}
```

3. Save the test event.
 

---

# Step 4 - Modify the Lambda Function

Replace the default response line:

```javascript
body: JSON.stringify('Hello from Lambda!'),
```

with:

```javascript
body: JSON.stringify('Hello ' + event.key1 + ' from Lambda!'),
```

1. Save the code.
2. Click **Deploy**.
 

---

# Step 5 - Test the Function

1. Click **Test**.
2. Review the **Execution Results**.
3. Expand **Details** to view the output.
 ![Pasted image 20260728231701](../../../images/Pasted%20image%2020260728231701.png)

---

# Step 6 - Upload Files to the S3 Bucket

1. Open **Amazon S3**.
2. Select the bucket created earlier.
3. Click **Upload**.
4. Add one or more files/folders.
5. Click **Upload**.

![Pasted image 20260728231714](../../../images/Pasted%20image%2020260728231714.png)![Pasted image 20260728231719](../../../images/Pasted%20image%2020260728231719.png)

> **Note:** Every file uploaded creates an event that triggers the Lambda function.

---

# Step 7 - Verify the Trigger

1. Return to the **Lambda** console.
2. Open your Lambda function.
3. Select the **Monitoring** tab.
4. Verify the invocation count has increased.

![Pasted image 20260728231726](../../../images/Pasted%20image%2020260728231726.png)

# Step 8 - Delete Resources

## Delete the Lambda Function

1. Open **Lambda**.
2. Select the function.
3. Click:

```text
Actions
    ↓
Delete
```

![Pasted image 20260728231750](../../../images/Pasted%20image%2020260728231750.png)

---

## Delete the S3 Bucket

1. Open **Amazon S3**.
2. Select the bucket.
3. Click **Empty**.
4. After the bucket is empty, click **Delete**.

![Pasted image 20260728231756](../../../images/Pasted%20image%2020260728231756.png)
