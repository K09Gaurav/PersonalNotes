# Lab: Deploy a Web Application Using AWS Elastic Beanstalk

## Objective

Create an Elastic Beanstalk application, deploy it to AWS, inspect the resources created automatically, and clean up the resources.

---

# Step 1 - Create an Application

1. Open the **AWS Management Console**.
2. Navigate to **Elastic Beanstalk**.
3. Click **Create Application**.
4. Enter an **Application Name**.
5. Click **Create**.

![Pasted image 20260728232115](../../../images/Pasted%20image%2020260728232115.png)![Pasted image 20260728232123](../../../images/Pasted%20image%2020260728232123.png)

---

# Step 2 - Create an Environment

1. Open the created application.
2. Click **Create new environment**.

![Pasted image 20260728232138](../../../images/Pasted%20image%2020260728232138.png)
---

## Configure the Environment

### Platform

Select:

```text
Node.js
```

### Service Role & Instance Profile

- Let **Elastic Beanstalk** automatically create/select the service role and instance profile.

### Networking

- Select the **VPC** created in the previous VPC lab.
- Select the **Public Subnet** created earlier.

### Monitoring

- Health Reporting:

```text
Basic
```

- Disable:

```text
Managed Platform Updates
```

5. Review the configuration.
6. Click **Create**.
 

---

# Step 3 - Access the Application

After deployment completes:

1. Open the Environment details page.
2. Copy the **Application URL (Domain)**.
3. Paste the URL into a web browser.

![Pasted image 20260728232202](../../../images/Pasted%20image%2020260728232202.png)![Pasted image 20260728232210](../../../images/Pasted%20image%2020260728232210.png)

---

# Step 4 - Inspect Automatically Created Resources

Elastic Beanstalk automatically provisions several AWS resources.

## EC2 Instance

1. Open the **EC2 Console**.
2. Verify the EC2 instance created for the application.
 

---

## Security Groups

1. In the EC2 Console, open **Security Groups**.
2. Review the automatically created firewall rules.
 

---

## Amazon S3

1. Open the **Amazon S3** console.
2. View the bucket automatically created for the application.
 

---

# Resources Created Automatically

Elastic Beanstalk provisions:

- Amazon S3 Bucket
- EC2 Instance(s)
- Auto Scaling Group
- EC2 Launch Template
- Security Groups
- CloudFormation Stack
- IAM Roles & Instance Profile
- Target Group (Load Balanced Environments)
- Application Load Balancer (Load Balanced Environments)
- CloudWatch Alarms (Optional)

---

# Step 5 - Cleanup Resources

## Terminate the Environment

1. Open **Elastic Beanstalk**.
2. Select the Environment.
3. Click:

```text
Actions
    ↓
Terminate Environment
```
 

---

## Delete the Application

After the environment is terminated:

1. Open **Applications**.
2. Select the application.
3. Click:

```text
Actions
    ↓
Delete Application
```
 

---

## Delete the S3 Bucket

1. Open **Amazon S3**.
2. Delete the bucket created by Elastic Beanstalk.
 

---

# Troubleshooting

## Error

```text
[VPC Name] is not attached to any internet gateway
```

### Resolution

- Verify that your VPC has an **Internet Gateway** attached.
- Ensure the Route Table contains:

```text
Destination: 0.0.0.0/0
Target: Internet Gateway
```
