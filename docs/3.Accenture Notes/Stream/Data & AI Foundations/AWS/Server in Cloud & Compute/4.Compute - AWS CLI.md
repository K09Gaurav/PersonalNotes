# Introduction

AWS provides multiple ways to interact with cloud resources.

The two most common methods are:

1. **AWS Management Console** (Graphical User Interface - GUI)
2. **AWS Command Line Interface (CLI)**

While the AWS Management Console is useful for beginners and visual management, developers, DevOps engineers, cloud engineers, and system administrators often prefer the **AWS CLI** because it allows AWS services to be managed programmatically and automated through scripts.

> [!IMPORTANT]
> **AWS CLI enables you to manage AWS services directly from a terminal or command prompt using commands instead of clicking through the AWS Console.**

---

# What is AWS CLI?

## Definition

The **AWS Command Line Interface (AWS CLI)** is a command-line tool that allows users to **access, manage, and automate AWS services** from a terminal or command prompt.

Instead of using the AWS Management Console (GUI), users execute commands to perform AWS operations.

For example, you can:

- Create EC2 instances
- Create S3 buckets
- Upload files
- Manage IAM users
- Launch databases
- Configure networking
- Delete resources

—all through simple terminal commands.

---

# Why Use AWS CLI?

The AWS CLI is widely used because it allows cloud resources to be managed quickly and efficiently.

Benefits include:

- Faster than using the AWS Console
- Easily automated using shell scripts
- Repeatable infrastructure operations
- Supports DevOps workflows
- Useful for remote server administration
- Access to features that may not yet be available in the AWS Console

---

# AWS CLI vs AWS Management Console

| AWS Management Console | AWS CLI |
|-------------------------|---------|
| Graphical Interface | Command Line Interface |
| Click buttons | Execute commands |
| Beginner friendly | Developer & DevOps friendly |
| Manual operations | Easily automated |
| Best for learning | Best for scripting and automation |

---

# How AWS CLI Works

The AWS CLI communicates directly with AWS services using the **AWS APIs**.

When you execute a command:

```bash
aws s3 ls
```

the CLI:

1. Authenticates your AWS account.
2. Sends an API request to AWS.
3. AWS processes the request.
4. AWS returns the response.
5. The CLI displays the result.

# AWS CloudShell

## Definition

AWS **CloudShell** is a browser-based terminal provided by AWS.

It includes:

- AWS CLI
- Linux shell
- Preconfigured AWS authentication

This eliminates the need to install or configure the AWS CLI locally.

---

## Advantages of CloudShell

- No installation required
- No manual configuration
- Accessible from any browser
- Integrated with AWS Console
- Ready to use immediately

# Basic AWS CLI Command Structure

Every AWS CLI command follows the same pattern.

```bash
aws <service> <operation> [options]
```

Example:

```bash
aws s3 ls
```

Where:

- `aws` → AWS CLI executable
- `s3` → AWS Service
- `ls` → Operation (List)

---

# AWS CLI Syntax

```text
aws
│
├── Service
│
├── Operation
│
└── Parameters
```

Example:

```bash
aws ec2 describe-instances
```

- Service → EC2
- Operation → describe-instances

---

# Example 1 – Creating an S3 Bucket

```bash
aws s3api create-bucket \
--bucket my-demo-bucket \
--region us-east-1
```

### Explanation

| Parameter | Description |
|-----------|-------------|
| aws | AWS CLI |
| s3api | S3 API commands |
| create-bucket | Creates a new bucket |
| --bucket | Bucket name |
| --region | AWS Region |

---

# Example 2 – Launching an EC2 Instance

```bash
aws ec2 run-instances \
--image-id ami-xxxxxxxx \
--count 1 \
--instance-type t2.micro \
--key-name my-keypair
```

### Explanation

| Parameter | Description |
|-----------|-------------|
| ec2 | EC2 service |
| run-instances | Launches an EC2 instance |
| image-id | Amazon Machine Image (AMI) |
| count | Number of instances |
| instance-type | Hardware configuration |
| key-name | SSH Key Pair |

# Common AWS CLI Commands

## List S3 Buckets

```bash
aws s3 ls
```

Lists all S3 buckets in your AWS account.

---

## List EC2 Instances

```bash
aws ec2 describe-instances
```

Displays information about EC2 instances.

---

## List IAM Users

```bash
aws iam list-users
```

Shows IAM users in the AWS account.

---

## Get Current AWS Region

```bash
aws configure get region
```

Displays the configured AWS Region.

---

## Check AWS CLI Version

```bash
aws --version
```

Shows the installed AWS CLI version.

---

# AWS CLI Configuration

Before using the CLI locally, AWS credentials must be configured.

This is done using:

```bash
aws configure
```

You will be prompted for:

- AWS Access Key ID
- AWS Secret Access Key
- Default Region
- Output Format (JSON, Table, Text)

# Interview One-Liners

**AWS CLI**
> A command-line tool that enables users to manage AWS services by executing commands instead of using the AWS Management Console.

**AWS CloudShell**
> A browser-based shell environment with the AWS CLI pre-installed and preconfigured for immediate use.

**AWS Management Console**
> A web-based graphical interface used to manage AWS resources manually.

**AWS SDK**
> A collection of programming libraries that allow applications to interact with AWS services using programming languages such as Java, Python, or JavaScript.

**AWS API**
> The underlying interface through which AWS services receive requests from the AWS Console, CLI, SDKs, or other clients.
