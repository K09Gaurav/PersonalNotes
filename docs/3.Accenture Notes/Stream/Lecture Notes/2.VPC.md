What is Amazon VPC?
 
VPC(Virtual Private Clouds)
 
-It is a service in AWS which will allow you to “provisioning a logically isolated section of AWS Cloud".
 
-It allows you to provision and deploy resources in a safe and secure manner.
 
-by default when you create a VPC, it is visible to the members present in that AWS itself. It is not visible to members in different account
 
-There are many VPCs within the AWS network which are isolated from each other
-What is IP address?
-You can create a VPC and define an IP address range that the VPC can use and this is done in the form of a CIDR block 
range (Classless Inter-Domain Routing).
 
-Exits in either in IPv4 or IPV6 address range
 
-Provides strict access rules for inbound and outbound traffic
 
-By default from a limitation perspective, you are allowed up to five VPCs per region per AWS account
  but if we need extra then...(you can request an increase in this limit by contacting AWS support, and they may approve a higher number depending on our specific use case and requirements & we can check and request a limit increase through the **AWS Service Quotas** console or by opening a support case in the AWS Support Center.)
 
 
 
 
Why VPC?
 
-It allows you to start deploying resources within your VPC securely. 
For example, different compute resources or storage or database and other network infrastructure

Types of IP address:
----------------------------------------
-IPV4 and IPV6 IP addresses:
   **IPv4** is the older version of the internet protocol that uses 32-bit addresses (e.g., `192.168.1.1`). It has about 4.3 billion unique addresses but is running out of space due to the increasing number of devices.
 
**IPv6** is the newer version with 128-bit addresses (e.g., `2001:0db8:85a3::`) and provides a much larger address space (340 undecillion addresses). it is designed to handle the growing number of devices connected to the internet.

Internet Engineering Task Force (IETF) and Advanced Research Projects Agency (ARPA): (Invented IPv6)
 
-In the early stages of the internet’s development, researchers and organizations, such as the Advanced Research Projects Agency (ARPA) and the Internet Engineering Task Force (IETF), collaborated to refine and standardize IP addressing.
 
-The original IP addressing scheme, known as IPv4, was introduced in the 1980s and used a 32-bit address format. As the internet grew in popularity, the need for more available addresses became apparent. This led to the development of IPv6, a newer version of IP addressing, which uses a 128-bit address format and provides a significantly larger pool of unique addresses.
 
-During the year of 1994, the Internet Engineering Task Force (IETF) initiated the development of the Internet Protocol version 6 (better known as IPv6).
 
-Pv6 was developed by the Internet Engineering Task Force (IETF) to deal with the long-anticipated problem of IPv4 address exhaustion, and was intended to replace IPv4.
 
 
-IANA (Internet Assigned Numbers Authority) delegated the responsibility for allocating IP address blocks to different areas across the globe to regional internet registries (RIRs), which then divide their address pools into smaller blocks delegated to ISPs.

# Class D (Multicast)
- **Address Range:** `224.0.0.0` to `239.255.255.255`
- **Purpose:** Reserved for **multicast** addresses. These addresses are used to send data to multiple devices at once, rather than to a specific device.
- **Usage:** Not for traditional host-to-host communication; instead, it's used to send data to a group of devices (multicast groups).
# Class E (Reserved for Future Use)
- **Address Range:** `240.0.0.0` to `255.255.255.255`
- **Purpose:** Reserved for **experimental** or **future use**. These addresses are not used for regular networking or public communication.
- **Usage:** It's not used for normal internet or network communication.

Q) What is Default Subnet Mask?
A) it is used to define which part of an IP address is the network and which part is for devices (hosts) within that network.
 
 
Example of Default Subnet Masks:
Class A IP Address: 10.0.0.1 with a subnet mask of 255.0.0.0
Network part: 10 (the first octet)
Host part: 0.0.1 (remaining three octets)
Class B IP Address: 172.16.0.1 with a subnet mask of 255.255.0.0
Network part: 172.16 (the first two octets)
Host part: 0.1 (remaining two octets)
Class C IP Address: 192.168.1.1 with a subnet mask of 255.255.255.0
Network part: 192.168.1 (the first three octets)
Host part: 1 (the last octet)
