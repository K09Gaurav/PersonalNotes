✅ How to Use PostgreSQL in Spring Boot

### Add PostgreSQL Dependency in pom.xml
```xml
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

If you're using Spring Data JPA, make sure this is also added:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```


### Configure PostgreSQL in application.properties

example from Drive Track Project :

```properties
spring.application.name=Analyzer
spring.datasource.url=jdbc:postgresql://localhost:5432/ProjectDB
spring.datasource.username=postgres
spring.datasource.password=password
spring.datasource.driver-class-name=org.postgresql.Driver

spring.profiles.active=dev

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect
logging.level.org.hibernate.SQL=DEBUG

server.port=8081

```

Explanation:

| Property                                      | Purpose                                                                                   |
| --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `spring.application.name=Analyzer`            | Sets the name of your app. Helpful in logs or cloud dashboards.                           |
| `spring.datasource.url=...`                   | JDBC URL that tells Spring where to find the PostgreSQL database.                         |
| `spring.datasource.username/password`         | Credentials used to authenticate with the database.                                       |
| `spring.datasource.driver-class-name=...`     | Explicitly sets the JDBC driver class for PostgreSQL. Often optional.                     |
| `spring.profiles.active=dev`                  | Activates the `dev` profile (you can define multiple profiles like `test`, `prod`, etc.). |
| `spring.jpa.hibernate.ddl-auto=update`        | Auto-creates or updates database tables based on your entity classes.                     |
| `spring.jpa.show-sql=true`                    | Prints the SQL queries generated by Hibernate.                                            |
| `logging.level.org.hibernate.SQL=DEBUG`       | Shows detailed SQL logs with values substituted into queries.                             |
| `spring.jpa.properties.hibernate.dialect=...` | Tells Hibernate to use PostgreSQL-specific SQL syntax.                                    |
| `server.port=8081`                            | Changes the default server port from 8080 to 8081.                                        |

START YOUR DB

can be done via docker

```bash
docker run --name pgdb \
  -e POSTGRES_DB=ProjectDB \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=password \
  -p 5432:5432 -d postgres
```
